# 面向对象编程（Object-Oriented Programming）

### 缩写：OOP

### 简述

以对象为基本建模与组织单元，通过封装、消息/方法、多态等组织大型系统的范式。强调把数据与行为放在一起并隐藏表示；滥用继承与贫血模型是常见偏差。

### 使用场景

业务领域建模、GUI、可扩展插件体系。

### 组成与要点

```text
封装 + 方法/消息 + 多态（继承需克制，组合优先）
```
### 实践与应用

• 组合优于继承
• 对象维护不变式
• 接口隔离

### 注意事项

• 为 OOP 而深层继承树
• 过程式代码硬塞进类

### 关联术语

• 对象 / 类：OOP 的基本单元
• 封装 / 继承 / 多态：常被并提的机制
• 领域模型：用对象表达业务
• 函数式编程：另一种主流组织方式（可对照）
