# 命令式编程（Imperative Programming）

### 缩写：无

### 简述

通过语句显式描述「如何逐步修改状态」以达成目标的范式。贴近硬件与控制流直觉，适合清晰的过程脚本；状态分散时难推理。

### 使用场景

系统脚本、算法步骤、性能敏感的就地更新。

### 实践与应用

• 局部可变、边界清晰
• 过程拆函数
• 关键状态集中管理

### 注意事项

• 全局可变蔓延
• 与并发共享冲突

### 对比与易混

| | 命令式 | 声明式 |
|--|--------|--------|
| 写法 | 一步步怎么做 | 要什么 |
| 状态 | 显式修改 | 常交给引擎 |

### 关联术语

• 声明式编程：侧重结果描述的对照
• 语句：命令式的主要书写单位
• 状态：通过修改状态推进计算
• 副作用：命令式中常见且显式
