# 声明式编程（Declarative Programming）

### 缩写：无

### 简述

侧重描述「要什么」而非逐步如何改状态的范式，如 SQL、许多 UI 视图描述、配置式基础设施。执行引擎负责策略；表达力强但调试执行计划更间接。

### 使用场景

查询、UI 视图、构建配置、规则引擎。

### 实践与应用

• 把意图写进结构
• 理解下层执行模型以免误用
• 性能问题看计划/层而非只看表面语法

### 注意事项

• 黑盒执行难控边角
• 泄漏抽象迫使写命令式补丁

### 对比与易混

| | 声明式 | 命令式 |
|--|--------|--------|
| 例子 | SQL、许多 UI 描述 | 逐步循环改数组 |
| 调试 | 常看执行计划/层 | 逐步断点更直观 |

### 关联术语

• 命令式编程：逐步改状态的对照
• 查询语言：声明式的常见实例（如 SQL）
• 纯函数：声明式变换的积木
• 引擎 / 运行时：负责「如何做」的执行方
