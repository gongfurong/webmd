# 函数式编程（Functional Programming）

### 缩写：FP

### 简述

以纯函数、不可变数据与函数组合为核心的范式，强调引用透明与声明式变换。利于测试与并发推理；与 IO、性能热点需务实互操作。

### 使用场景

数据变换管道、并发安全逻辑、解析与编译器前端。

### 组成与要点

```text
纯函数 + 不可变数据 + 组合（map/filter/reduce…）
IO 放边缘
```
### 实践与应用

• 纯核心+非纯边缘
• 用映射过滤归约表达变换
• 控制分配与惰性

### 注意事项

• 过度抽象点自由
• 忽视运行时分配成本

### 关联术语

• 纯函数 / 不可变：FP 常用支柱
• 高阶函数：组合行为的核心
• 声明式：FP 常呈现声明式风格
• 面向对象：以对象为中心的对照范式
