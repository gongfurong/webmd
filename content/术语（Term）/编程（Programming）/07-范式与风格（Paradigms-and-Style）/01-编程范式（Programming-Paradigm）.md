# 编程范式（Programming Paradigm）

### 缩写：无

### 简述

指导如何组织程序结构与推理方式的总体风格类别，如命令式、声明式、面向对象、函数式等。语言可多范式；选型影响抽象手段、测试方式与团队习惯，而非绝对对错。

### 为何出现

同一问题可有多种组织方式；范式提供可复用的思维与结构模板。

### 使用场景

技术选型、代码评审标准、教学与重构方向。

### 实践与应用

• 按问题选范式而非宗教站队
• 在一种语言内先掌握其主流范式
• 混合时明确边界

### 注意事项

• 为范式而范式
• 团队范式不统一导致风格撕裂

### 对比与易混

| 范式 | 更强调 |
|------|--------|
| 命令式 | 如何改状态 |
| 声明式 | 要什么结果 |
| OOP | 对象与消息 |
| FP | 纯函数与组合 |

### 关联术语

• 命令式 / 声明式：描述「如何做」与「要什么」
• 面向对象 / 函数式：组织代码的主流范式
• 语言：一门语言可支持多种范式
