# 面向切面（Aspect-Oriented Programming）

### 缩写：AOP

### 简述

把横切关注点（日志、事务、鉴权）从主业务逻辑中分离为切面并织入的技术取向。减少重复；过度使用会令控制流不透明。

### 使用场景

事务边界、统一日志、权限检查。

### 实践与应用

```text
业务方法
  ↑ 织入
横切：日志 / 事务 / 鉴权
```
### 注意事项

• 调试栈难懂
• 切面顺序依赖

### 关联术语

• 中间件：请求链上的横切包装（近形）
• 装饰器：包装行为的语言机制
• 关注点分离：把横切逻辑拆出的目标
• 日志 / 事务：典型横切关注点
