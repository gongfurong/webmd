# 关键字（Keyword）

### 缩写：保留字（常近义）

### 简述

由编程语言规定、具有特殊语法角色、通常不可作普通标识符使用的词（如条件、声明、可见性相关词）。它们是语法骨架的固定部件；与库函数名不同，关键字的含义由语言定义，不能在用户空间随意重定义（少数语言有情境关键字等例外）。

### 使用场景

阅读语法、避免命名冲突、设计代码生成时转义或换名。

### 实践与应用

• 学新语言时集中浏览关键字表，建立语句形态地图。
• 生成代码时检测目标语言保留字并处理。

### 注意事项

```text
// 勿用语言关键字当变量名
// 生成代码时检测保留字
```
### 关联术语

• 标识符：用户可命名的符号（通常避开关键字）
• 语法：关键字是语法骨架的一部分
• 语句：许多控制结构由关键字引入
