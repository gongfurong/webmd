# 标识符（Identifier）

### 缩写：无

### 简述

用于命名程序实体（变量、函数、类型、模块等）的符号，通常由语言规定的字符集与规则构成。好的标识符承载领域含义，是可读性与协作的第一界面；错误命名会放大误解，但标识符本身不提供类型或生命周期保证（那些由其它规则约束）。

### 使用场景

命名变量与 API、代码评审、避免保留字冲突、国际化标识（部分语言允许 Unicode 名）。

### 实践与应用

```text
// 可读：orderTotal    难读：ot / x1
// 公开 API 改名 = 兼容性事件
```
### 注意事项

• 过度缩写与误导性名称导致误用。
• 与关键字冲突会导致语法错误。
• 依赖大小写区分的语言中，仅大小写不同的名易混淆。

### 关联术语

• 关键字：通常不可用作普通标识符的保留词
• 作用域：标识符可见的区域
• 绑定：名称与存储或值的关联
• 命名空间：避免名称冲突的分区
