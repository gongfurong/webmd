# 源代码（Source Code）

### 缩写：源码（口语）

### 简述

用编程语言书写的、供人阅读与修改的程序文本。它是协作、评审与版本演进的主载体；经编译、解释或转译后才变为机器或虚拟机可直接执行的形式。源码本身通常不能直接当最终运行形态。

### 使用场景

开发与代码评审、缺陷定位、开源协作、安全审计（供应连中的源码可见性）、生成文档与测试。

### 在体系中的位置

### 实践与应用

• 以可读性与模块边界组织目录与命名。
• 关键意图用结构与命名表达，注释补「为什么」而非复述「做什么」。
• 构建可复现：同一提交应能得到等价产物。

### 注意事项

• 丢失源码只留产物会难以维护与审计。
• 生成代码与手写代码混用时要标明来源与是否可改。
• 密钥、口令不得写入源码库。

### 对比与易混

• 目标代码/字节码/机器码：面向执行器的形态。
• 伪代码：表达算法意图，通常不可直接执行。

### 关联术语

• 程序：源码所描述的可执行意图集合
• 编译器：将源码译为其它可执行形态
• 解释器：直接读取并执行源码或中间表示
• 模块：源码的组织与依赖边界
• 构建：从源码生成可部署产物的过程
