# 数据结构（Data Structure）

### 缩写：无

### 简述

在计算机中组织与存储数据的方式，以及其上允许的操作集合。数组、链表、栈、队列、树、哈希表、图等提供不同的访问、插入、删除与关系表达能力。数据结构选择往往比微优化代码路径更能决定性能与复杂度上限。

### 使用场景

建模领域关系、API 返回形状、缓存与索引、算法实现基础。

### 实践与应用

| 访问模式 | 更常考虑 |
|----------|----------|
| 按下标随机访问 | 数组/切片类 |
| 按键查找 | 哈希表 / 映射 |
| 频繁头尾增删 | 双端队列等 |
| 层级/图关系 | 树 / 图 |

### 注意事项

• 通用结构误用（如用列表当高频成员检测）导致隐性平方复杂度。
• 过早使用复杂结构增加维护成本。
• 并发下的结构需要额外安全策略。

### 关联术语

• 算法：在结构上执行的计算过程
• 类型：结构在语言中的类型表达
• 抽象数据类型：对外操作契约，与具体实现可分离
• 内存布局：实现层的存放方式（影响性能）
