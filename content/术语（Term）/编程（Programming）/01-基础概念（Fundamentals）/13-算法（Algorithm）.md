# 算法（Algorithm）

### 缩写：无

### 简述

在有限步骤内解决一类问题的明确计算过程：输入、输出与中间变换规则。算法独立于具体编程语言，但实现受数据结构与语言模型约束。复杂度（时间/空间）描述资源随输入增长的趋势，是选型与性能讨论的共同语言。

### 使用场景

选型排序/查找/图算法、评估性能、面试与教学、关键路径优化。

### 组成与要点

```text
输入 → 有限步骤变换 → 输出
（常同时讨论：正确性、时间/空间复杂度）
```
### 实践与应用

• 先明确问题规模与约束再选算法，避免过早微优化。
• 用大 O 等与实测结合：渐近与常数因子都重要。
• 正确性优先：先不变量与边界，再谈加速。

### 注意事项

• 教科书最优在真实缓存/IO 下未必最快。
• 业务规则复杂时「算法」瓶颈可能在错误的抽象层。
• 专利与许可偶尔约束特定算法使用（合规场景需专业确认）。

### 关联术语

• 数据结构：算法操作与组织数据的方式
• 复杂度：资源随输入增长的趋势描述
• 程序：算法在具体语言中的实现
• 正确性：算法是否满足规格
