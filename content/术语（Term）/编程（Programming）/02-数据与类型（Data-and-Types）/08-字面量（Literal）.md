# 字面量（Literal）

### 缩写：无

### 简述

在源码中直接写出值的记号，如数字、字符串、布尔、空、集合字面量。是值的字面语法形式，类型与驻留策略由语言定义。

### 使用场景

初始化、测试数据、模式匹配常量。

### 实践与应用

```text
42    "hi"    true    null    [1, 2]    {a: 1}
// 有业务含义的字面量 → 抽成命名常量
```
### 注意事项

• 浮点字面量精度
• 巨大字面量影响可读与初始化

### 关联术语

• 值：字面量所表示的对象
• 常量：常由字面量初始化的命名
• 编码：字符串字面量涉及的字符到字节规则
