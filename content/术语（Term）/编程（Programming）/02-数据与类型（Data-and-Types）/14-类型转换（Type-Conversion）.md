# 类型转换（Type Conversion）

### 缩写：无

### 简述

将值从一种类型视角变为另一种：隐式强制或显式转换/断言。合理转换连接异构接口；隐式强制与盲目断言是缺陷高发区。

### 使用场景

字符串与数字、数值拓宽收窄、动态边界进入静态世界。

### 实践与应用

• 优先显式转换并处理失败
• 禁止仅为过编译的断言
• 边界用解析而非硬转

### 注意事项

```text
// 反例：无依据强转 / 断言「先过编译」
// 边界：parse + 失败处理 优于 硬转
```
### 关联术语

• 类型：转换的两端
• 解析：从文本等外部形态得到类型化值（常优于硬转）
• 类型断言：在部分语言中强行当作某类型（有风险）
• 校验：转换失败时的处理
