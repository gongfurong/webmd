# 泛型（Generics）

### 缩写：无

### 简述

通过类型参数使同一逻辑安全复用于多种具体类型的机制。在保持检查的同时减少重复；约束限制类型参数必须具备的能力。

### 使用场景

容器、通用算法、仓储接口。

### 实践与应用

```text
List<T>
function id<T>(x: T): T
// 一套逻辑，类型参数随调用处变化
```
### 注意事项

• 过度泛型损害可读
• 类型擦除带来的运行时限制

### 关联术语

• 类型参数：泛型的核心机制
• 多态：参数多态的一种形式
• 集合：泛型最常见的应用场景
• 类型推断：调用处常靠推断填类型参数
