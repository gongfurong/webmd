# 类型推断（Type Inference）

### 缩写：无

### 简述

由检查器根据上下文自动得出类型、减少显式标注的机制。保持静态保证的同时降低噪音；推断过宽或失败时应显式标注以固定意图。

### 使用场景

局部变量、泛型调用、可省略的返回类型。

### 实践与应用

```text
let x = 1        // 推断
function f(x: T) // 边界显式更稳
```
### 注意事项

• 推断不是无类型
• 复杂推断报错需拆表达式

### 关联术语

• 静态类型：推断服务的类型体系
• 类型注解：显式写出类型（推断不足时使用）
• 泛型：推断常作用于类型参数
• 编译器 / 检查器：执行推断的工具
