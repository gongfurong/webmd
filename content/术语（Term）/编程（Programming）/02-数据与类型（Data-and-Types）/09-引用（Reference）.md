# 引用（Reference）

### 缩写：无

### 简述

指向对象或存储位置的句柄，使多方共享同一目标。传引用与传拷贝导致不同的别名与副作用；部分语言以指针、借用等模型精细管理引用。

### 使用场景

大对象传参、图数据、观察者、避免拷贝。

### 实践与应用

• 文档写清共享可变还是快照
• 并发共享引用需同步或改为不可变共享

### 注意事项

• 悬挂引用（手动内存管理）
• 意外别名导致隐蔽修改

### 对比与易混

| | 共享引用 | 独立拷贝 |
|--|----------|----------|
| 修改可见性 | 多方看到同一改动 | 互不影响 |
| 成本 | 常更轻 | 可能更重 |

### 关联术语

• 值：被引用的对象内容或拷贝语义的对照
• 可变性：通过引用共享修改的风险来源
• 所有权：部分语言中管理引用寿命的规则
• 别名：多个引用指向同一目标
