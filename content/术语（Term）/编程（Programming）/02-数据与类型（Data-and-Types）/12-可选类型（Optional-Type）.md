# 可选类型（Optional Type）

### 缩写：无

### 简述

在类型层显式表达有值或没有的构造（Optional、Maybe、T? 等），迫使处理缺席分支。把空从隐式风险变为可检查状态。

### 使用场景

查找、可选配置、部分字段解析。

### 组成与要点

```text
Optional<T> = Some(值) | None
// 使用前处理两种分支
```
### 实践与应用

• 避免无依据的强解包
• 用语言组合子或早期返回传播可选

### 注意事项

• 可选嵌套过深
• 缺席与失败原因不应混为一谈

### 关联术语

• 空值：可选所要驯服的缺席标记
• 联合类型：表达「多种可能」的近亲机制
• 模式匹配：安全解包可选的常用方式
• 错误类型：失败原因不宜与单纯缺席混用
