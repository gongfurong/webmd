# 空值（Null）

### 缩写：无

### 简述

表示没有值或不可用的特殊标记（null、nil、None、undefined 等）。空值传播导致的空引用错误极为常见；宜用可选类型、明确错误或多态空对象削弱危害。

### 使用场景

可选字段、查找未命中、短暂未初始化。

### 实践与应用

• 用可选类型表达可缺席
• 入口拒绝非法空
• 区分没有与空串/零的业务含义

### 注意事项

```text
SQL 三值逻辑：TRUE / FALSE / UNKNOWN
NULL 比较与聚合语义需单独处理
```
### 关联术语

• 三值逻辑：SQL 语义
• 约束：非空约束
• 聚合：NULL 忽略规则需注意
