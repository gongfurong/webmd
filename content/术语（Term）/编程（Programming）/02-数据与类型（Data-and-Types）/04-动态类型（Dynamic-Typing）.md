# 动态类型（Dynamic Typing）

### 缩写：无

### 简述

类型主要附着于运行时的值，操作时才检查是否支持的策略。利于快速试验与动态元编程；类错误易推迟到具体运行路径，需测试与校验弥补。

### 使用场景

脚本、原型、插件与高度动态配置。

### 实践与应用

• 关键路径补测试与校验
• 对外 API 做结构校验
• 可渐进引入类型检查

### 注意事项

• 路径覆盖不足时线上才暴露类型错误
• 鸭子类型约定在重构时较脆

### 对比与易混

| | 动态类型 | 静态类型 |
|--|----------|----------|
| 类型附着 | 运行时的值 | 名与表达式 |
| 反馈 | 执行到才可能报错 | 编写/构建期可拦一批 |

### 关联术语

• 静态类型：检查偏执行前的对照策略
• 运行时：动态检查发生的时机
• 鸭子类型：按可用操作而非名义类型协作
• 单元测试：动态语言中弥补类错误前移的常见手段
