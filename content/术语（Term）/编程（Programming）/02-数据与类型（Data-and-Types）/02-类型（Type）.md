# 类型（Type）

### 缩写：无

### 简述

对值的集合及其上允许操作的分类与约束，回答「是什么、能做什么」。静态类型多在编译期检查，动态类型多在运行期检查。类型用于防错、文档化接口与辅助优化，不能替代全部业务规则校验。

### 为何出现

无约束时错误操作往往很晚才暴露；类型把整类错误前移或明确化。

### 使用场景

函数签名、字段定义、API 契约、重构安全网。

### 组成与要点

```text
类型 ≈ 值的集合 + 允许的操作 +（可选）检查时机
```
### 实践与应用

• 公共边界写清类型或运行时校验
• 用类型表达不变式
• 动态语言可用注解与检查器增强

### 注意事项

• 类型通过不等于可省略测试
• any 等逃逸口会掏空类型收益

### 对比与易混

• 类是实现类型的一种机制，类型还可是接口、别名、联合等

### 关联术语

• 值：类型所分类的对象
• 静态类型 / 动态类型：检查时机的两种策略
• 类型推断：由上下文推出类型
• 泛型：类型参数化的复用
• 接口：以契约描述能力的类型形态
