# 编码（Character Encoding）

### 缩写：无

### 简述

将字符映射为字节序列的规则（如 UTF-8）。语言内部字符串表示与对外字节可能不同；错误编解码导致乱码与协议/安全问题。

### 使用场景

文件、HTTP 正文、数据库连接、日志。

### 实践与应用

```text
字符 ──编码──▶ 字节序列 ──解码──▶ 字符
// Web/跨平台默认倾向 UTF-8，并在边界声明
```
### 注意事项

• 平台默认编码差异
• 截断多字节字符
• 同形字绕过过滤

### 关联术语

• Unicode：现代字符码点标准
• UTF-8：Web 与跨平台常见的字节映射
• 字符串：语言中的文本类型
• 序列化：结构化数据落盘/传输时常叠编码问题
