# Unicode（Unicode）

### 缩写：无

### 简述

为全球文字与符号分配统一码点的标准，是现代字符串处理基础。UTF 系列是其编码形式。需区分码点、代码单元与用户感知的字素簇。

### 使用场景

国际化、搜索与规范化、显示截断。

### 组成与要点

```text
码点（抽象字符） → UTF-8/16/32（字节形态）
注意：一个可见字素可能多个码点/代码单元
```
### 实践与应用

• 可见截断按字素簇
• 比较前考虑规范化形式

### 注意事项

• 一个代码单元不等于一个可见字符
• 表情与组合字符长度

### 关联术语

• 编码：码点到字节的具体映射（UTF-8/16 等）
• 字符串：语言对文本的运行时表示
• 国际化：面向多语言用户的应用需求
• 规范化：比较与搜索前的码点正规化
