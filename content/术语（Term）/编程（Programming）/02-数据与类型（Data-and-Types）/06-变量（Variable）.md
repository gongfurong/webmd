# 变量（Variable）

### 缩写：无

### 简述

将标识符与存储位置或值绑定的抽象，用于在作用域内读取与（若允许）更新。变量有作用域与生命周期；可变绑定与不可变绑定影响推理与并发。

### 使用场景

中间结果、循环状态、资源句柄、闭包捕获。

### 组成与要点

```text
标识符 ──绑定──▶ 存储位置 / 当前值
         （受作用域与可变规则约束）
```
### 实践与应用

• 缩小作用域，靠近使用处声明
• 优先不可变绑定
• 避免一变量先后表示不同概念

### 注意事项

• 未初始化读取
• 闭包捕获可变变量陷阱
• 全局变量隐式耦合

### 关联术语

• 常量：不可再绑定（或更深不可变）的名字
• 作用域：变量可见范围
• 引用：变量可能持有的间接句柄
• 绑定：名称与存储/值的关联
