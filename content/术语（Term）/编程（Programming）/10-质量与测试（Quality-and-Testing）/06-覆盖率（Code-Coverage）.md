# 覆盖率（Code Coverage）

### 缩写：无

### 简述

度量测试执行触及了多少代码结构（行、分支等）的指标。高覆盖不保证高质量；零覆盖区域值得关注。应用覆盖率作信号而非唯一目标。

### 使用场景

看未测区域、门禁阈值、评审辅助。

### 实践与应用

• 看分支覆盖关键逻辑
• 禁止为了覆盖写无断言测试

### 注意事项

```text
// 反例：无断言的测试只为刷行覆盖
覆盖率 = 触及范围信号 ≠ 正确性证明
```
### 对比与易混

• 覆盖率不是缺陷率

### 关联术语

• 软件测试：覆盖率所度量的活动
• 分支覆盖：比行覆盖更严格的结构指标
• 质量门禁：用覆盖阈值作信号（勿神化）
• 断言：无断言的覆盖无意义
