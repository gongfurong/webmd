# TypeScript（TypeScript）

### 缩写：TS

### 简述

在 JavaScript 上增加可选静态类型与部分未来语法的超集语言，编译（擦除类型）后输出 JS。用类型提升大型代码库可维护性；类型是开发期契约，运行时仍需对外部数据校验。

### 使用场景

中大型前后端 JS 代码库、共享类型的全栈项目、库的类型声明。

### 实践与应用

```text
// 开发期：类型检查
// 构建：擦除类型 → JavaScript
// 反例：any / 乱断言掏空类型收益
```
### 注意事项

• 反例：用 `any` / 无依据断言让类型「通过」——类型收益被掏空，运行时仍可能炸。
• any 泛滥
• 类型断言造假
• 类型与运行时行为不一致的错觉

### 关联术语

• JavaScript：编译后的运行目标与语法超集基础
• 静态类型：TS 的主要增值
• 类型推断：减少标注
• 转译：输出可运行 JS 的过程
