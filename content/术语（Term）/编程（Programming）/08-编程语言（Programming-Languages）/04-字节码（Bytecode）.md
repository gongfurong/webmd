# 字节码（Bytecode）

### 缩写：无

### 简述

面向虚拟机或解释器的可移植中间指令序列，由语言前端生成。字节码解耦语言与具体机器，便于分发与 JIT；不同 VM 字节码不通用。

### 使用场景

Java/CLR/.py 等托管执行、沙箱、热更新讨论。

### 组成与要点

```text
源码 → 前端编译 → 字节码 → VM 解释 / JIT
```
### 实践与应用

• 版本兼容与类文件格式
• 安全上注意不可信字节码加载

### 注意事项

• 反编译不等于源码语义全恢复

### 关联术语

• 虚拟机：执行字节码的引擎
• 编译器：生成字节码的前端
• JIT：把字节码再编为本地码
• 可移植性：与具体 CPU 指令解耦
