# 编译器（Compiler）

### 缩写：无

### 简述

将源码翻译为另一目标表示（常为机器码、字节码或另一高级语言）的程序。编译期可做优化与静态检查；编译器正确性与诊断质量影响开发体验。

### 使用场景

构建产物、跨平台编译、语言前端。

### 实践与应用

• 固定编译器版本保证可复现
• 阅读诊断而非只看第一处错误
• 区分编译错误与链接错误

### 注意事项

• 未定义行为被优化「吃掉」
• 优化级别改变时序假设

### 对比与易混

| | 编译器 | 解释器 |
|--|--------|--------|
| 路径 | 先译后跑 | 边读边跑 |
| 产物 | 常有独立产物 | 可不落盘 |

### 关联术语

• 解释器：直接执行的对照路径
• 字节码：常见中间产物
• JIT：运行中再编译热点
• 语法 / 语义：编译前端分析的对象
