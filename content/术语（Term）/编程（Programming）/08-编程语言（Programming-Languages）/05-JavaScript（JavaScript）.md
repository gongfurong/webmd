# JavaScript（JavaScript）

### 缩写：JS

### 简述

以事件驱动与原型对象模型著称的高阶动态语言，是浏览器中的主力程序语言，也广泛用于服务端与工具链。核心机制包括作用域、闭包、this 绑定、原型链与基于期约的异步模型；浏览器 DOM、Fetch 等属于宿主提供的平台 API，不是语言核心语法的一部分。

### 使用场景

浏览器交互、服务端 JS 运行时、跨端与工具脚本。

### 组成与要点

```text
宿主事件循环 + 原型对象模型 + 一等函数/闭包 + 期约异步
// DOM/Fetch 等是宿主 API，不是语言核心语法
```
### 实践与应用

• 严格理解相等、提升、闭包与 this
• 异步用期约/async 统一错误
• 模块化显式依赖

### 注意事项

• 反例：把 `this` 绑定、隐式全局、`==` 强制转换当成「随便写也能对」——应固定团队子集（严格相等、模块化、明确绑定）。
• 隐式全局
• 类型不稳导致的运行时错误
• 勿把宿主平台 API 当成语言语法本身

### 演进要点

ECMAScript 逐年增特性；以目标运行时支持矩阵为准。

### 关联术语

• TypeScript：可选类型的超集语言
• 事件循环：JS 宿主常见的并发模型
• 闭包 / 原型：语言核心机制
• ECMAScript：语言标准名称
• 期约 / async：异步编排
