# Java（Java）

### 缩写：无

### 简述

静态类型、基于类的面向对象语言，运行于 JVM 生态，强调可移植字节码与成熟工具链。广泛用于企业后端、安卓（历史与并存）与大数据生态；内存模型与并发工具箱完善。

### 使用场景

后端服务、中间件、大型企业系统。

### 组成与要点

```text
源码 → javac → 字节码 → JVM（GC、JIT）
```
### 实践与应用

• 理解引用语义与相等
• 善用并发工具而非手写锁
• 关注 GC 与分配

### 注意事项

• 空引用
• 过度继承
• 版本与模块系统演进差异

### 关联术语

• JVM：字节码运行时
• 静态类型：语言类型策略
• 垃圾回收：自动内存管理
• 类 / 接口：OOP 主模型
