# Go（Go）

### 缩写：无

### 简述

静态类型、语法精简、自带并发原语（goroutine/channel）与工具链的语言，编译为本地代码，常用于云服务、CLI 与基础设施。错误以值返回为惯用；接口满足隐式。

### 使用场景

微服务、网络代理、运维工具、云原生组件。

### 实践与应用

```text
go func() { ... }()     // goroutine
// 错误：if err != nil { return err }
// 取消：context 贯通
```
### 注意事项

• nil 接口陷阱
• goroutine 泄漏
• 泛型使用保持克制清晰

### 关联术语

• 并发：goroutine 与通道模型
• 静态类型：编译期检查
• 错误：惯用错误值返回
• 模块：依赖与版本管理
