# Rust（Rust）

### 缩写：无

### 简述

强调内存安全与零成本抽象的系统级语言，通过所有权、借用与生命周期在编译期消除整类内存与数据竞争错误。适合系统、嵌入式、性能敏感服务；学习曲线集中在所有权模型。

### 使用场景

系统组件、高性能服务、WebAssembly、替代 C/C++ 的安全场景。

### 组成与要点

```text
所有权 + 借用 + 生命周期 → 编译期挡下一批内存/数据竞争问题
```
### 实践与应用

• 先设计所有权边界
• Unsafe 隔离最小化
• 利用类型状态机

### 注意事项

• 与外部 FFI 边界风险集中
• 过度 clone 掩盖设计问题

### 关联术语

• 所有权：内存安全核心模型
• 借用：临时访问规则
• 静态类型：编译期保证
• 并发：类型系统协助的数据竞争防范
