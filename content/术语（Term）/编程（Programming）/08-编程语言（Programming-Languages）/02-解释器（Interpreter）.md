# 解释器（Interpreter）

### 缩写：无

### 简述

直接读取并执行源码或中间表示、而不必先生成独立机器码产物的执行方式。启动快、易交互；热路径性能通常不如本地编译，可结合 JIT。

### 使用场景

脚本、REPL、嵌入式策略语言。

### 实践与应用

• 注意解释执行热路径成本
• 用分析器找热点
• 关键库可原生扩展

### 注意事项

• 依赖解释器版本差异
• 源码直接暴露的分发问题

### 对比与易混

| | 解释器 | 编译器 |
|--|--------|--------|
| 启动 | 常更快上手 | 可能更重构建 |
| 峰值性能 | 常较低（可加 JIT） | 本地码潜力大 |

### 关联术语

• 编译器：先译后跑的对照
• 运行时：解释执行的环境
• REPL：交互式解释的界面
• 字节码：亦可被解释执行的中间码
