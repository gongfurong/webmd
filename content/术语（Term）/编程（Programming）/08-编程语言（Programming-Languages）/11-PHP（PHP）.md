# PHP（PHP）

### 缩写：无

### 简述

最初面向 Web 请求-响应模型的动态语言，在服务端网页与 CMS 生态中广泛使用。现代 PHP 增强了类型与工具，但历史全局与松散实践仍需纪律约束。

### 使用场景

传统服务端网页、内容管理、部分 API。

### 组成与要点

```text
请求进入 → 脚本执行 → 响应结束（传统共享一无长驻状态假设，视部署而定）
```
### 实践与应用

• 用现代框架的自动加载与类型
• 请求结束即释放的模型要理解
• 输入过滤与输出转义

### 注意事项

• 老式全局与混写 HTML
• 编码与时区配置

### 关联术语

• 动态类型：传统默认
• Web 请求模型：历史主场景
• 模板：与 HTML 混排的常见形态
• 包管理器：现代依赖管理
