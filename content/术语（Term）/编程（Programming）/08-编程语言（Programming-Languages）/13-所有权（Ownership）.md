# 所有权（Ownership）

### 缩写：无

### 简述

一种资源（尤其是内存）在同一时刻由唯一所有者负责释放、转移或借用的规则体系。Rust 等语言将其做进类型系统；其它语言可用惯例与智能指针近似。所有权消灭双释放与悬垂引用整类问题。

### 使用场景

系统编程、无 GC 性能路径、明确生命周期的 API。

### 组成与要点

```text
值唯一所有者
  ├─ 移动：所有权转交，原名失效
  └─ 借用：临时只读或独占写，到期归还
```
### 实践与应用

• API 用类型表达借用还是转移
• 减少共享可变
• 图结构用索引或 arena 等模式

### 注意事项

• 循环引用需弱引用等打破
• 错误套用到有 GC 语言造成过度复杂

### 关联术语

• 借用：非获取所有权的临时访问
• 生命周期：引用有效期的约束
• 移动语义：所有权转移
• RAII：资源随作用域获取释放
