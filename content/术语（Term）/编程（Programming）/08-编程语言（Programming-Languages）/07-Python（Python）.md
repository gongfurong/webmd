# Python（Python）

### 缩写：无

### 简述

强调可读性的高阶动态语言，标准库广泛，常用于脚本、数据、Web 后端与自动化。缩进语法、万物对象与 GIL（CPython）等实现特征影响并发模型选择。

### 使用场景

后端服务、数据脚本、运维自动化、机器学习胶水。

### 实践与应用

```text
venv 隔离依赖
# CPU 密集：多进程或本地扩展（GIL 下线程不适合纯计算）
```
### 注意事项

• 依赖与版本碎片
• GIL 下线程不适合 CPU 密集

### 关联术语

• 解释器：CPython 等实现
• 动态类型：默认类型策略
• 虚拟环境：依赖隔离
• 包管理器：安装分发生态
