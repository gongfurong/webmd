# 构建（Build）

### 缩写：无

### 简述

从源码与资源生成可部署产物的过程：编译、打包、资源处理、生成代码等。可复现构建是可靠发布的前提；构建脚本本身也是需维护的代码。

### 使用场景

本地开发、CI、发布制品。

### 组成与要点

```mermaid
flowchart LR
  源码与依赖 --> 编译打包 --> 制品
```
### 实践与应用

• 构建可在干净环境复现
• 缓存与增量要正确失效
• 密钥不进入不可信日志

### 注意事项

• 隐式依赖本机脏状态
• 非确定性时间戳导致产物漂移

### 关联术语

• 编译器：构建流水线中的翻译步骤
• 制品：构建输出
• 依赖：构建输入的外部库
• 持续集成：自动构建的常见宿主
