# 代码格式化（Code Formatting）

### 缩写：无

### 简述

按机械规则统一空白、换行与简单布局的工具化实践。消除风格争论，降低 diff 噪音；与语义 lint 不同，格式化通常不改行为。

### 使用场景

提交前、CI 检查、团队统一风格。

### 实践与应用

```text
保存时/提交前/CI：同一套 formatter
// 与 lint（语义规则）分开配置
```
### 注意事项

• 大爆炸式全库格式化淹没历史
• 生成代码要排除或统一

### 关联术语

• 静态分析：格式化偏机械外观，lint 偏语义规则
• 代码评审：减少风格噪音
• 构建 / CI：可强制格式一致
