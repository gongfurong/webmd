# 静态分析（Static Analysis）

### 缩写：无

### 简述

在不执行程序（或不全量执行）的情况下检查源码的技术，含类型检查、lint、漏洞模式扫描等。用于早期发现缺陷与统一风格；误报需要调参。

### 使用场景

CI 门禁、IDE 提示、安全扫描。

### 实践与应用

• 规则集与语言版本对齐
• 增量引入避免噪音淹没
• 安全规则与风格规则分层

### 注意事项

• 误报导致屏蔽一切
• 无法取代测试

### 对比与易混

| | 静态分析 | 测试 |
|--|----------|------|
| 是否执行程序 | 通常不/不全量 | 执行 |
| 强项 | 早发现模式问题 | 验证真实行为 |

### 关联术语

• 类型检查：一类静态分析
• 代码检查器（lint）：风格与缺陷模式
• 测试：动态验证的对照
• 编译器：常内置部分静态检查
