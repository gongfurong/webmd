# 交互式解释环境（Read-Eval-Print Loop）

### 缩写：REPL

### 简述

读取输入、求值、打印结果并循环的交互环境，用于探索 API、快速验证假设与教学。不可替代自动化测试与可复现脚本。

### 使用场景

探索库、调试表达式、数据试算。

### 实践与应用

```text
read → eval → print → loop
// 有价值的试验沉淀为测试或脚本
```
### 注意事项

• 依赖 REPL 隐藏的导入状态
• 不可复现的手工步骤

### 关联术语

• 解释器：REPL 的执行引擎
• 脚本：可复现的命令序列（对照手工试验）
• 调试：探索性验证假设
• 求值：输入表达式的立即计算
