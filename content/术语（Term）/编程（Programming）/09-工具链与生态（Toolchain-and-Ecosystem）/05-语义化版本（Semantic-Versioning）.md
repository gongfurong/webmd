# 语义化版本（Semantic Versioning）

### 缩写：SemVer

### 简述

用主.次.修订版本号传达兼容性意图的约定：主版本不兼容变更，次版本兼容新增，修订兼容修复。依赖解析与升级策略常基于此；前发行标签另有约定。

### 使用场景

发库版本、写版本约束、判断升级风险。

### 组成与要点

```text
主.次.修订
主：不兼容    次：兼容新增    修订：兼容修复
```
### 实践与应用

• 破坏性变更升主版本
• 约束范围与团队风险偏好匹配
• 变更日志对齐 SemVer

### 注意事项

• 宣称 SemVer 但不遵守
• 0.x 阶段规则更松

### 关联术语

• 依赖：版本约束的书写对象
• 包管理器：按约束解析版本
• 变更日志：版本含义的文字说明
• 兼容性：主版本升级的破坏性信号
