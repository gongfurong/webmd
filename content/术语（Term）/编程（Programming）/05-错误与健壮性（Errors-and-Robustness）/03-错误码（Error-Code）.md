# 错误码（Error Code）

### 缩写：无

### 简述

用枚举或数值/字符串代码表示失败类别的方式，常见于 C 风格 API、HTTP 状态与跨语言边界。错误码稳定可协议化，但易被忽略，需配合强制检查或结果类型。

### 使用场景

系统调用、HTTP、嵌入式、跨进程协议。

### 实践与应用

• 代码稳定可文档化
• 与人类可读消息分离
• 包装为结果类型防忽略

### 注意事项

• 忽略返回码
• 语义重叠的代码表

### 对比与易混

| | 错误码 | 异常 |
|--|--------|------|
| 跨边界 | 易协议化 | 依赖语言运行时 |
| 处理 | 必须检查返回 | 可集中 catch |

### 关联术语

• 错误：码所标识的失败
• 异常：另一类错误表达
• HTTP 状态码：跨网络边界的错误码形态（应用层）
• 结果类型：强制处理错误码的包装方式
