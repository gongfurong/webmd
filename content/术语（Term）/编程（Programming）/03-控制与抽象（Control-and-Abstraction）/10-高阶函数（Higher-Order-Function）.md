# 高阶函数（Higher-Order Function）

### 缩写：无

### 简述

接收函数作参数或返回函数的函数，是行为参数化与组合的基础。映射、过滤、归约、中间件装饰器等均属此类用法。

### 使用场景

集合处理、中间件链、依赖注入式回调、DSP 管道。

### 实践与应用

```text
map(列表, f)
filter(列表, pred)
// 「对每个元素做什么」作为参数传入
```
### 注意事项

• 回调地狱可读性
• 性能上过度分配闭包

### 关联术语

• 函数：作为参数或返回值被传递
• 闭包：常作为高阶函数的实参
• 函数组合：把小函数接成管道
• 中间件：请求链上高阶包装的常见形态
