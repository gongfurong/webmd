# 函数（Function）

### 缩写：无

### 简述

将一段可复用逻辑命名并封装、通过参数接收输入并通过返回值（及可能副作用）给出结果的抽象。函数是模块化与测试的基本单元；一等函数可把行为当作值传递。

### 为何出现

重复逻辑复制粘贴难维护；需要可组合的抽象单元。

### 使用场景

业务步骤封装、回调、工具库、API 处理函数。

### 组成与要点

```text
函数名(参数…) → 返回值
       ↘ 可能的副作用
```
### 实践与应用

• 单一职责，短小可测
• 参数表清晰，避免布尔开关迷宫
• 纯函数优先，副作用靠边

### 注意事项

• 过长参数列表
• 隐式依赖全局
• 递归无基线

### 关联术语

• 参数与返回值：函数的输入输出契约
• 闭包：函数捕获定义环境后的形态
• 方法：附着于对象/类型的函数
• 纯函数：无副作用的特殊函数
• 模块：函数的组织单元
