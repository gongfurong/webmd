# 抽象（Abstraction）

### 缩写：无

### 简述

隐藏细节、只暴露与当前目标相关的本质接口的过程与结果。好抽象降低认知负荷并隔离变化；坏抽象错误隐藏导致泄漏与僵化。抽象层级应与稳定边界对齐。

### 使用场景

API 设计、分层、封装第三方、领域模型。

### 实践与应用

• 先有用例再抽接口
• 抽象以变化点为依据
• 允许在证据下打破或下沉抽象

```text
// 反例：过早抽象 → 错误隐藏细节（泄漏抽象）
// 先有用例，再抽稳定边界
```
### 关联术语

• 封装：隐藏表示、保护不变式的近亲原则
• 接口：对外暴露的能力契约
• 模块：抽象的落地边界
• 泄漏抽象：被迫关心下层细节时的失败模式
