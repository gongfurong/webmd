# 作用域（Scope）

### 缩写：无

### 简述

标识符在程序文本中可见与可访问的区域。块级、函数级、模块级、全局等规则决定绑定寿命与遮蔽关系。正确理解作用域才能避免意外全局与闭包缺陷。

### 使用场景

变量声明位置、模块导出、名称遮蔽排查。

### 组成与要点

```text
外层作用域
  └─ 内层作用域   // 可见外层；内层可遮蔽外层名
```
### 实践与应用

• 尽量小作用域
• 避免依赖隐式全局
• 注意块级与函数级差异

### 注意事项

• 内层遮蔽外层导致误读
• 提升/hoisting 造成的时序错觉（部分语言）

### 关联术语

• 绑定：名称在作用域内的关联
• 闭包：延长或捕获外围作用域
• 模块：模块级可见性
• 命名空间：跨模块的名称分区
