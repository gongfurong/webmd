# 循环（Loop）

### 缩写：无

### 简述

重复执行某段逻辑直到条件满足或集合耗尽的控制结构。for/while 与迭代器协议是常见形态。循环是性能热点与死循环风险的集中地，边界与终止条件必须明确。

### 使用场景

批处理、遍历集合、重试等待、游戏与仿真主循环。

### 实践与应用

• 明确终止条件与最大次数
• 优先用映射/过滤等表达意图
• 注意 off-by-one

### 注意事项

```text
// 必须：明确终止条件或有界次数
while cond: ...   // cond 永真 → 死循环
```
### 关联术语

• 迭代器：按需提供下一元素以支撑遍历
• 递归：用自调用表达重复的对照手法
• 控制流：循环是重复路径的结构
• 复杂度：循环层数常影响渐近成本
