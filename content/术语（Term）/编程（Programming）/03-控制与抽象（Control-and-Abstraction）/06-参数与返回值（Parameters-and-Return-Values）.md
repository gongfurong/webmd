# 参数与返回值（Parameters and Return Values）

### 缩写：无

### 简述

参数是函数输入的名字与约束；返回值是函数向调用方交回的结果。传值/传引用、默认参数、可变参数、多返回值或结果类型因语言而异。清晰的输入输出是接口契约的核心。

### 使用场景

API 设计、重载/缺省、错误用返回值还是异常的选择。

### 实践与应用

```text
// 输入：参数（含默认/可变参数，视语言）
// 输出：返回值 或 错误/结果类型
// 反例：一长串布尔开关参数
```
### 注意事项

• 可变默认参数陷阱（部分语言）
• 忽略返回值导致错误吞没

### 关联术语

• 函数：参数与返回值所属的抽象
• 类型：参数与返回的类型约束
• 错误处理：失败用返回值还是异常的选择
• 不可变：参数是否被就地修改的约定
