# 分支（Branching）

### 缩写：无

### 简述

根据条件选择不同执行路径的控制结构，如 if/else、switch/match。分支表达决策；过多分支暗示可改用多态、表驱动或数据建模。

### 使用场景

权限判断、状态处理、特性开关、输入分类。

### 实践与应用

```text
if cond: A
else if other: B
else: C
// 状态多时：表驱动 / 模式匹配 / 多态 优于深层 if
```
### 注意事项

• 遗漏默认分支
• 条件顺序导致的遮蔽
• 嵌套三元过度

### 关联术语

• 控制流：分支是路径选择手段
• 布尔：条件表达式的常见结果类型
• 模式匹配：更结构化的多路分支
• 多态：用类型分派减少手写分支
