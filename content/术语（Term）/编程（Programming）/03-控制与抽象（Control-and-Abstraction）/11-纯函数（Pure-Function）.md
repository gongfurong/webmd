# 纯函数（Pure Function）

### 缩写：无

### 简述

相同输入必得相同输出且不产生可观察副作用的函数。纯函数易测、易缓存、易并行推理；真实系统在边界组合非纯操作。

### 使用场景

领域计算、变换管道、属性测试、并发安全逻辑。

### 实践与应用

• 核心业务规则尽量纯
• IO 与时间、随机放边缘
• 用纯函数降低回归成本

### 注意事项

• 隐藏全局读写破坏纯度
• 依赖「当前时间」即非纯

### 对比与易混

| | 纯函数 | 非纯 |
|--|--------|------|
| 相同输入 | 相同输出 | 可能不同 |
| 副作用 | 无 | 可能有 IO/全局修改 |

### 关联术语

• 副作用：纯函数所排除的可观察影响
• 引用透明：可用结果替换调用的性质
• 测试：纯逻辑更易单测
• 不可变：常与纯函数一起使用
