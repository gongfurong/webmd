# 迭代器（Iterator）

### 缩写：无

### 简述

按需依次提供序列中下一元素的对象或协议，把「如何遍历」与「遍历时做什么」分离。支持惰性序列、流式处理与统一 for-each 语法；耗尽与可重用性因实现而异。

### 使用场景

大集合惰性映射、流式读文件、管道式数据处理。

### 实践与应用

```text
it = iter(集合)
while (x = next(it)) 非结束:
  使用 x
```
### 注意事项

• 迭代中改底层集合
• 无限迭代器无限制消费

### 关联术语

• 循环：消费迭代器的常见语法
• 生成器：惰性产生序列的近亲机制
• 集合：迭代的典型来源
• 惰性求值：管道式 map/filter 的基础
