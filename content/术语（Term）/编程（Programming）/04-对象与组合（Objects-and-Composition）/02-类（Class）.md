# 类（Class）

### 缩写：无

### 简述

用于创建对象的模板或类型定义，描述字段、方法与初始化约定。类建立了对象的形状与行为契约；与接口/协议相比，类常绑定具体实现继承体系。

### 使用场景

OOP 代码组织、类型层次、框架扩展点。

### 组成与要点

```text
类 ──实例化──▶ 对象
含：字段形状、方法、构造约定
```
### 实践与应用

• 组合优于深层继承
• 构造后满足不变式
• 密封/最终类限制不必要扩展

### 注意事项

• 继承用于复用实现导致脆弱基类
• 构造函数中调用可覆写方法

### 关联术语

• 对象：类所创建的实例
• 继承：类之间的「是一种」关系
• 接口：与具体类分离的契约
• 构造：实例初始化过程
