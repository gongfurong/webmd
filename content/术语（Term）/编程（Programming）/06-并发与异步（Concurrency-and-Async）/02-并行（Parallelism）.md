# 并行（Parallelism）

### 缩写：无

### 简述

同时使用多个计算资源执行工作以缩短墙钟时间。并行需要可分解的工作与可扩展的硬件；错误的并行可能因同步开销更慢。

### 使用场景

数据并行计算、渲染、批量运算、多核利用。

### 实践与应用

• 测量后再并行
• 注意假共享与调度开销
• 保持任务粒度合适

### 注意事项

• 不可分割的串行瓶颈
• 并行化非线程安全库

### 对比与易混

| | 并行 | 并发 |
|--|------|------|
| 焦点 | 墙钟时间、多算力 | 结构与交互 |
| 典型 | 数据切开多核算 | 多请求交替处理 |

### 关联术语

• 并发：可重叠推进的结构（未必同时执行）
• 线程：共享内存并行的常见载体
• CPU 密集：适合并行加速的工作类型
• 数据并行：把数据切开同时算
