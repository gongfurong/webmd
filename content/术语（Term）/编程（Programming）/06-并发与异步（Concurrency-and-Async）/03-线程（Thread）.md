# 线程（Thread）

### 缩写：无

### 简述

操作系统或运行时中可独立调度的执行流，共享进程地址空间。多线程提高吞吐与响应，但共享内存并发需同步；线程创建与切换有成本。

### 使用场景

服务器工作线程、后台任务、并行计算。

### 实践与应用

• 线程池复用
• 最小化共享可变
• 避免阻塞线程池

### 注意事项

• 线程泄漏
• 栈大小与过多线程
• 锁顺序死锁

### 对比与易混

| | 线程 | 进程 |
|--|------|------|
| 内存 | 共享进程空间 | 独立地址空间 |
| 隔离 | 弱 | 强 |
| 通信 | 共享内存+同步 | IPC |

### 关联术语

• 进程：更强隔离的执行实例
• 锁：保护线程间共享数据
• 并发：多线程是实现手段之一
• 异步：可用少量线程服务大量等待
