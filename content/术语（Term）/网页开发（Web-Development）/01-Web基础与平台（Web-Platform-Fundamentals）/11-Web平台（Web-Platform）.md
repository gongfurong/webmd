# Web平台（Web Platform）

### 缩写：无

### 简述

由标记语言、样式、脚本、Web API、安全模型与浏览器实现共同构成的、可在其上构建文档与应用的能力集合。平台通过标准演进扩展能力（存储、媒体、设备、性能等），并受兼容性与权限约束。

### 使用场景

技术选型、能力检测、评估某功能是否「能在 Web 做」。

### 组成与要点

```text
HTML + CSS + JS + Web API + 安全模型 + 浏览器实现
```
### 实践与应用

• 以基线/兼容数据决定用哪些 API
• 渐进增强：核心路径不依赖最前沿能力
• 权限类 API 在用户手势与说明后请求

### 注意事项

• 标准有草案与实现差距
• 同一 API 在安全上下文（HTTPS）才可用

### 演进要点

能力持续通过标准与实现迭代；以目标浏览器矩阵为准。

### 关联术语

• HTML / CSS / JS：核心技术层
• Web API：平台能力接口
• 浏览器：实现载体
• 安全上下文：强能力前提
