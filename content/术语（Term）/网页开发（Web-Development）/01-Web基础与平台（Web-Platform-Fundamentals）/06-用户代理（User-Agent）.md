# 用户代理（User Agent）

### 缩写：UA

### 简述

代表用户访问 Web 的客户端软件，浏览器是最常见形态，亦包括爬虫、命令行客户端、内嵌 WebView 等。协议与服务器常通过 User-Agent 字符串识别客户端类型，但该字符串可伪造，不宜作为唯一安全依据。

### 使用场景

内容协商、统计分析、兼容分支（应谨慎）、反爬讨论。

### 实践与应用

• 能力检测优先于 UA 嗅探
• 服务端日志可记录 UA 作辅助
• 对爬虫与浏览器给出合理的缓存与配额策略

### 注意事项

```text
// 反例：仅靠 User-Agent 字符串做鉴权或安全判定（可伪造）
// 优先：能力检测 / 服务端权威校验
```
### 对比与易混

• 浏览器：一类用户代理；用户代理：更广的客户端概念

### 关联术语

• 浏览器：最常见 UA
• User-Agent 字符串：可伪造的自报身份
• 爬虫：另一类 UA
