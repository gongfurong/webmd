# 网站（Website）

### 缩写：无

### 简述

在统一品牌、域名或组织边界下，一组相互链接的网页与相关资源的集合，并通常提供导航与信息架构。网站侧重发布与组织结构；同一技术栈也可承载偏应用的产品，但「站」强调可浏览的资源与入口集合。

### 使用场景

企业官网、内容门户、文档站、营销站点群。

### 实践与应用

```text
信息架构 ↔ URL 结构 ↔ 导航
公开索引路径 / 需鉴权路径 分开
```
### 注意事项

• 多子域/多仓库导致体验与规范分裂
• 无 404 与重定向策略的死链

### 关联术语

• 网页：组成单元
• 域名：站点入口名
• 信息架构：内容组织
• CDN：静态加速常见手段
