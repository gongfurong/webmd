# Web应用（Web Application）

### 缩写：无

### 简述

以 Web 技术（文档、样式、脚本、Web API）交付、在用户代理中运行并提供持续交互与业务能力的应用形态。相对静态内容站，更强调状态、权限、数据读写与客户端逻辑；仍受同源、安全与网络约束。

### 使用场景

后台管理系统、在线协作、电商结算流、SaaS 控制台。

### 组成与要点

```text
UI（HTML/CSS）+ 脚本 + 后端 API/身份 + 数据
状态：URL / 客户端 / 服务端权威 分层
```
### 实践与应用

• 划分客户端状态与服务端权威状态
• 鉴权与 CSRF/XSS 等边界一并设计
• 关键流程支持刷新、回退与深链

### 注意事项

• 把桌面软件假设直接搬到浏览器而无离线/权限模型
• 过重客户端导致首屏与 SEO/可访问性受损（视产品目标）

### 对比与易混

• 网页/网站：偏文档与发布；Web 应用：偏交互与业务闭环
• 原生应用：安装与系统 API 模型不同，可与 Web 混合

### 关联术语

• 网页：载体形态之一
• API：前后端协作界面
• SPA / MPA：常见交付形态
• 身份认证：业务闭环常见依赖
