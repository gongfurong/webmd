# 超链接（Hyperlink）

### 缩写：无

### 简述

从一处资源指向另一资源（或同文档片段）的可激活引用，是超文本导航的基本操作。链接可带关系类型、下载提示与安全属性（如 rel 与跨源打开策略），影响 SEO、安全与打开方式。

### 使用场景

导航、引用、分页、外链、深链到应用状态。

### 实践与应用

```html
<a href="/path">可读标签</a>
<!-- 外链按需 rel="noopener" 等 -->
```
### 注意事项

• 用可点击 div 代替链接导致可访问性与 SEO 受损
• javascript: 伪协议滥用
• 未校验的用户提供链接成为钓鱼面

### 关联术语

• URL：链接目标
• 超文本：链接所在形态
• a 元素：HTML 中的链接
