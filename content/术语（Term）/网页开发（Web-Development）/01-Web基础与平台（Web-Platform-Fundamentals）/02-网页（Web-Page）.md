# 网页（Web Page）

### 缩写：无

### 简述

由标记、样式与可选脚本等组成、经用户代理获取并呈现给用户的一个可导航文档单元。传统上对应一次文档导航的主要资源；在现代应用中也可能是应用壳或路由下的一个视图，但仍以「可获取的文档/资源树」为理解起点。

### 使用场景

内容站文章页、落地页、应用内路由视图、打印与分享的基本单元。

### 实践与应用

• 每个重要状态尽量有可分享的 URL
• 首屏所需关键资源可识别、可测量
• 语义结构服务可访问与可发现

### 注意事项

• 把「一个 HTML 文件」与「用户感知的一页」简单等同（SPA 下常分离）
• 仅客户端状态导致无法分享与刷新丢失

### 对比与易混

| | 网页 | 网站 | Web 应用 |
|--|------|------|----------|
| 粒度 | 可导航文档单元 | 页面与资源的集合 | 持续交互与业务 |

### 关联术语

• 网站：页面集合
• HTML：结构标记
• URL：可分享入口
• DOM：运行时文档树
