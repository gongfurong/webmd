# 层叠样式表（Cascading Style Sheets）

### 缩写：CSS

### 简述

描述 Web 文档表现的样式语言：选择器匹配元素并应用声明；层叠决定冲突时的胜出规则。结构归 HTML，表现宜集中在 CSS。

### 使用场景

视觉、布局、主题、响应式、打印样式。

### 组成与要点

```text
选择器 { 属性: 值; }
层叠 ≈ 来源 + 重要性 + 特异性 + 顺序
```

### 实践与应用

• 先布局后装饰
• 用自定义属性管理令牌
• 避免过深选择器

### 注意事项

• !important 滥用
• 结构与表现耦合

### 关联术语

• 选择器：匹配规则
• 盒模型：尺寸基础
• 层叠与优先级：冲突裁决
