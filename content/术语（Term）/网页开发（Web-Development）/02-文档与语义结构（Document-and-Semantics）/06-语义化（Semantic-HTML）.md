# 语义化（Semantic HTML）

### 缩写：无

### 简述

选用能表达内容含义与结构角色的 HTML 元素与属性，而非仅用无语义容器配合样式。语义化改善可访问性、可维护性与机器理解（含搜索与阅读模式），是结构层质量的基础。

### 为何出现

纯表现标记使辅助技术与维护者无法从结构得知含义。

### 使用场景

标题层级、导航、主内容、文章、列表、按钮与链接区分。

### 实践与应用

```html
<nav>…</nav>
<main>
  <article>
    <h1>…</h1>
  </article>
</main>
```
### 注意事项

• 为 SEO 堆砌无意义标签
• 用标题只为了字号

### 关联术语

• HTML 元素：语义载体
• 可访问性：语义的重要收益
• SEO：可发现性相关
