# 元素（HTML Element）

### 缩写：无

### 简述

HTML 文档中由开始标签、内容与结束标签（或空元素形式）界定的结构单元，具有标签名与属性，对应 DOM 中的元素节点。元素选择决定默认语义、可访问角色与可包含的内容模型。

### 使用场景

排版结构、交互控件、媒体嵌入、脚本与元数据。

### 实践与应用

```html
<button type="button">操作</button>
<!-- 反例：用 div 冒充按钮且不可聚焦 -->
```
### 注意事项

• 错误嵌套被浏览器静默修复导致结构意外
• 交互元素误用不可聚焦标签

### 关联术语

• 属性：元素的配置
• DOM：运行时节点
• 语义化：选对元素类型
