# 超文本标记语言（Hypertext Markup Language）

### 缩写：HTML

### 简述

用于描述 Web 文档结构与部分语义的标记语言：元素、属性组成文档树，再由浏览器解析为 DOM 并参与渲染与可访问性树。HTML 管「结构与含义」，表现与行为通常由 CSS 与脚本分担。

### 为何出现

需要与传输、样式解耦的、可链接可解析的文档结构描述。

### 使用场景

任何网页骨架、邮件部分子集、服务端渲染输出。

### 组成与要点

```html
<!DOCTYPE html>
<html>
  <head>…元数据…</head>
  <body>…内容…</body>
</html>
```
### 实践与应用

• 先正确结构再美化
• 用语义元素表达角色
• 校验嵌套与闭合习惯

### 注意事项

• 用 div 堆一切丢失语义
• 把表现信息硬编码进无意义标签

### 演进要点

HTML 以活标准演进；以目标浏览支持为准。

### 关联术语

• 元素 / 属性：构成材料
• DOM：解析后的树
• CSS：表现层
• 语义化：选用含义贴切的元素
