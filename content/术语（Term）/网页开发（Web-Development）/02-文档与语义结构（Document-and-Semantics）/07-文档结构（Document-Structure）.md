# 文档结构（Document Structure）

### 缩写：无

### 简述

HTML 文档从 doctype、html 根、head 元数据到 body 内容的组织方式，以及 body 内标题、地标与章节的层次。清晰结构支撑样式、脚本挂载点与辅助技术导航。

### 使用场景

脚手架模板、布局框架、CMS 输出。

### 组成与要点

```text
doctype → ```html
          ├─ head（元数据/资源）
          └─ body（地标与内容层级）
```
### 实践与应用

• head 放元数据与关键资源提示
• body 内单一主内容地标
• 标题层级不跳级滥用

### 注意事项

• 多个 main
• 地标重复且无名称区分

### 关联术语

• head / body：两大分区
• 地标元素：导航与主内容
• 语义化：结构表达含义
