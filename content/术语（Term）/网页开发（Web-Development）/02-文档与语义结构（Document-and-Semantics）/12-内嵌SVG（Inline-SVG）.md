# 内嵌SVG（Inline SVG）

### 缩写：无

### 简述

将 SVG 标记直接写入 HTML 文档，作为文档树一部分参与样式、脚本与可访问性。相对 img 引用的 SVG，内联可更细粒度控制，但增大 HTML 体积并需注意安全与缓存。

### 使用场景

图标系统、可样式化矢量、需脚本交互的图形。

### 实践与应用

```html
<svg role="img" aria-label="…">…</svg>
<!-- 装饰性：aria-hidden="true" -->
```
### 注意事项

• 不可信 SVG 内联的 XSS 面
• 过大内联影响首字节与缓存粒度

### 关联术语

• 图像：引用式 SVG 的对照
• 可访问性：标题与角色
• CSS：可样式化矢量
