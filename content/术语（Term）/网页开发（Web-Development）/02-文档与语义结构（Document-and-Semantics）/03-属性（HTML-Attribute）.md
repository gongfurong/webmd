# 属性（HTML Attribute）

### 缩写：无

### 简述

写在开始标签上、为元素提供附加信息的名值对（部分为布尔属性）。属性描述初始配置与语义；运行时 DOM 属性（property）与 HTML 属性并不总是一一同步，脚本读写时需区分。

### 使用场景

id/class、链接地址、表单名、无障碍属性、数据属性。

### 实践与应用

• 全局唯一 id 谨慎使用
• 布尔属性按 HTML 规则书写
• data-* 存非样式非行为的轻量数据

### 注意事项

• 混淆 attribute 与 property
• 在属性中内联大量业务状态

### 对比与易混

| | HTML 属性 | DOM 属性（property） |
|--|-----------|----------------------|
| 来源 | 标记初始配置 | 运行时对象字段 |
| 同步 | 不总是双向同步 | 以运行时为准时需查规范 |

### 关联术语

• 元素：属性所挂载对象
• DOM property：运行时对照概念
• data-*：自定义数据属性
