# 插槽（Slot）

### 缩写：无

### 简述

在 Web 组件等模型中，允许外部把子内容投递到组件内部指定位置的占位机制。默认插槽与具名插槽分离布局与内容，实现组合式 UI 结构。

### 使用场景

设计系统组件、卡片标题/操作区扩展点。

### 组成与要点

```text
组件外壳
  ├─ slot 默认
  └─ slot name="actions"
外部子内容投递到对应槽位
```
### 实践与应用

• 具名插槽表达稳定扩展点
• 文档化每个插槽用途
• 避免过深插槽迷宫

### 注意事项

• 插槽内容的样式与事件边界易混淆
• 无障碍焦点在组件边界需额外设计

### 关联术语

• Web 组件：插槽所在模型
• 组合：内容投影式复用
