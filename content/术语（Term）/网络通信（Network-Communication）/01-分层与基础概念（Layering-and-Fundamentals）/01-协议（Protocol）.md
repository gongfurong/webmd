# 协议（Protocol）

### 缩写：无

### 简述

通信双方对格式、时序与语义的约定；分层栈中每层协议职责不同。「有协议」不等于实现符合协议，也不是某个产品名。

### 使用场景

选型、互操作争议、抓包解读、标准演进讨论。

### 组成与要点

```text
约定 = 报文格式 + 时序/状态机 + 错误与版本语义
分层栈中：每层协议各管一段
```
### 实践与应用

• 问清：状态机谁定义、错误如何表示、版本如何演进。
• 排障先锁定失败发生在哪一层协议语义。

### 注意事项

• 无文档私有协议的长期成本高。
• 实现偏离标准会导致「同名协议不同行为」。

### 关联术语

• 封装：上层数据装入本层 PDU 的过程
• 标准/RFC：协议的规范文本来源
• API 契约：应用层接口约定（近形）
