# TCP-IP模型（TCP-IP Model）

### 缩写：无

### 简述

描述互联网协议族的实践分层（链路/网络/传输/应用，教材或称四/五层）。文件名用 TCP-IP 避免路径中的「/」；口语仍常说 TCP/IP 模型。

### 使用场景

工程文档中的层次边界、与 OSI 对照。

### 实践与应用

• 按职责归位：重传多在传输层，路由在网络层，业务语义在应用层。
• 遇 QUIC 等「跨传统层」协议时用职责而非层号硬套。

### 注意事项

• 不同教材层数命名略有差异，对齐时说明口径。

### 对比与易混

| TCP/IP 常见分层 | 大致对应 |
|-----------------|----------|
| 应用 | HTTP、DNS… |
| 传输 | TCP / UDP |
| 网络 | IP |
| 链路 | 以太网等 |

### 关联术语

• OSI 模型：七层对照参考
• IP / TCP / UDP / HTTP：各层代表协议
