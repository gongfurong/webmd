# 套接字（Socket）

### 缩写：无

### 简述

操作系统向应用暴露的网络端点抽象（地址族+类型+协议，常绑定 IP 与端口）。是编程接口，不是 HTTP 之类应用协议本身。

### 使用场景

编写/排查网络程序、连接池、fd 耗尽。

### 组成与要点

```text
Socket ≈ 协议族 + 类型 + 本地/对端地址绑定
应用 ⇄ 套接字 API ⇄ 传输协议
```
### 实践与应用

• 分清阻塞/非阻塞与多路复用模型。
• 监控 fd/句柄上限与 TIME_WAIT 对短连接的影响。

### 注意事项

• 套接字仍 ESTABLISHED ≠ 对端业务健康。
• SO_REUSEADDR 等选项有副作用，需知其语义。

### 关联术语

• 端口：套接字地址的一部分
• TCP / UDP：常见传输类型
• 进程：套接字的使用主体
