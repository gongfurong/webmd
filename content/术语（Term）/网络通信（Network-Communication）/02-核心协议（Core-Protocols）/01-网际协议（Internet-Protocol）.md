# 网际协议（Internet Protocol）

### 缩写：IP

### 简述

网络层寻址与分组转发的核心（IPv4/IPv6）。尽力投递，不保证可靠与顺序；IP 可达 ≠ 应用可用。

### 使用场景

寻址规划、路由排障、双栈、分片/PMTU 问题。

### 组成与要点

```mermaid
flowchart LR
  主机A -->|IP 分组转发| 路由器 --> 主机B
```
### 实践与应用

• 先确认解析到的地址族与路由是否达。
• 大包/隧道场景查分片与 PMTUD 是否被 ICMP 策略拦。

### 注意事项

• 私网+NAT 下「源 IP」身份不可靠。
• 只 ping 通不能证明业务端口与协议正常。

### 关联术语

• TCP / UDP：承载于 IP 之上的传输
• 路由：IP 分组如何转发
• 地址：IPv4/IPv6 标识主机接口
