# 传输控制协议（Transmission Control Protocol）

### 缩写：TCP

### 简述

面向连接的可靠字节流：确认、重传、排序、流控与拥塞控制。可靠≠无限等；应用仍要超时与业务幂等。

### 使用场景

多数「不能乱丢」的业务通道：Web、库连接、RPC over TCP。

### 实践与应用

• 观测重传率、RTT、零窗口、握手失败。
• 短连接看握手成本；长连接看中间盒空闲策略。

### 注意事项

• 队头阻塞：单流丢包拖累后续。
• TIME_WAIT 堆积常来自无脑短连接。

### 对比与易混

| | TCP | UDP |
|--|-----|-----|
| 语义 | 可靠字节流 | 数据报 |
| 有序 | 排序交付 | 不保证 |
| 队头阻塞 | 单流丢包可拖累后续 | 无连接级重传语义 |

### 关联术语

• UDP：不可靠数据报对照
• 三次握手 / 四次挥手：连接建立与释放
• 流控 / 拥塞控制：发送速率调节
• TLS：常叠加的信道安全
