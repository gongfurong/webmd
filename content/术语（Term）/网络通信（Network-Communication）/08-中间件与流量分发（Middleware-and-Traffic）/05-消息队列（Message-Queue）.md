# 消息队列（Message Queue）

### 缩写：MQ

### 简述

异步消息中间件：削峰、解耦、缓冲。投递语义因产品而异；发进队列 ≠ 业务成功，消费者通常需幂等。

### 使用场景

最终一致流程、削峰填谷、发布订阅。

### 组成与要点

```text
生产者 → 队列/主题 → 消费者
关注：投递语义、积压、顺序、死信
```
### 实践与应用

• 明确至少一次/至多一次等语义并配幂等键。
• 监控积压与死信，设降级策略。

### 注意事项

• 全局顺序昂贵；分区顺序更常见。
• 与同步 RPC 选错会导致难排的时序问题。

### 关联术语

• 异步：解耦的时间形态
• 重试 / 死信：失败处理
• 幂等：消费者安全重试前提
