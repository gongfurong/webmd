# 内容分发网络（Content Delivery Network）

### 缩写：CDN

### 简述

在边缘缓存/就近分发内容以降低延迟、减轻源站。对可缓存静态最有效；动态 API 不保证「上了就快」。

### 使用场景

静态资源、下载分发、部分动态加速与边缘防护。

### 组成与要点

```mermaid
flowchart LR
  用户 --> 边缘节点
  边缘节点 -->|未命中| 源站
```
### 实践与应用

• 设计缓存键与 Cache-Control；区分命中与回源排障。
• 回源保护与敏感响应不可被公共缓存。

### 注意事项

• 错误缓存→脏数据或隐私泄漏。

### 关联术语

• 缓存：边缘命中的核心
• DNS：调度用户到边缘
• 源站：回源目标
