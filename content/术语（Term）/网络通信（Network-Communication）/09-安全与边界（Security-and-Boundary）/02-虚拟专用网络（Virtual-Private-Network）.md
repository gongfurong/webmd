# 虚拟专用网络（Virtual Private Network）

### 缩写：VPN

### 简述

在公网上建加密隧道，近似专网连通或特定隐私路径。上线 ≠ 终端可信；注意分流与隧道 MTU。

### 使用场景

远程办公接入、站点互联。

### 组成与要点

```text
明文业务 ─封装加密─▶ 公网 ─解封装─▶ 内网
```
### 实践与应用

• 分清接入 VPN vs 站点到站点；选全隧道/拆分隧道。
• 预留封装开销，联调 MTU。

### 注意事项

• 出口 IP 变为 VPN 出口，影响封禁与审计。
• 密钥/证书疏于轮换。

### 关联术语

• 加密隧道：核心机制
• 防火墙：边界策略协同
• 远程访问：典型场景
