# 远程过程调用（Remote Procedure Call）

### 缩写：RPC

### 简述

把远程调用做得像本地方法的交互范式；底层仍是网络消息。gRPC 等是实现，不是 RPC 的全部。

### 使用场景

内网微服务、IDL 二进制调用。

### 实践与应用

• 默认加超时、熔断、可观测；写路径考虑幂等。
• 控制同步调用链深度。

### 注意事项

• 本地错觉掩盖部分失败与重复执行。
• 与消息异步的边界要有意选择。

### 对比与易混

| | RPC | 本地调用 |
|--|-----|----------|
| 失败模式 | 网络/超时/部分执行 | 通常同进程 |
| 延迟 | 高几个数量级 | 低 |

### 关联术语

• API：更广的接口概念
• 超时 / 重试 / 幂等：分布式调用三件套
• 序列化：参数与返回值的编码
