# 全表扫描（Full Table Scan）

### 缩写：无

### 简述

依次读取表（或聚簇）中大部分/全部行以过滤结果。小表或低选择性条件时可能是合理选择；大表高频出现则常是性能问题信号。

### 使用场景

解释计划中的 Seq Scan/ALL、评估是否缺索引。

### 实践与应用

• 对比「加索引后是否仍扫表」。
• 大表报表改仓库或覆盖索引。
• 注意隐式转换导致无法用索引而扫表。

### 注意事项

• 并非所有全表扫描都该消灭。
• 并行扫描仍耗 IO。

### 对比与易混

| | 全表扫描 | 索引查找 |
|--|----------|----------|
| 适合 | 结果占比大 | 高选择性 |

### 关联术语

• 索引查找：对照路径
• 优化器：代价选择
• 选择性：决策因素
