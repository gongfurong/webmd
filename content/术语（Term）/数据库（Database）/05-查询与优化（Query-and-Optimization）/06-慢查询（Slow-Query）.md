# 慢查询（Slow Query）

### 缩写：无

### 简述

执行时间超过阈值的 SQL，是性能治理的主要抓手。阈值应结合 SLA，而非固定魔法数。

### 使用场景

开启慢日志、APM、周会性能榜、容量预警。

### 实践与应用

• 设阈值并采样；按总耗时=次数×单次排序。
• 每条慢 SQL 绑定负责人与优化回访。
• 区分偶发锁等待与稳定差计划。

### 注意事项

• 只盯平均忽略次数会漏「略慢但极热」。
• 脱敏后再分享日志。

### 对比与易混

慢查询 vs 高 CPU 会话；vs 锁等待。

### 信号与度量

慢查询条数、P99、扫描行数、锁等待占比。

### 关联术语

• 执行计划：分析入口
• 索引：常见治理手段
• 观测：慢日志
