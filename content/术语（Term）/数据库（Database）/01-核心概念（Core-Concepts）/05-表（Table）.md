# 表（Table）

### 缩写：无

### 简述

关系模型中存放同类行的二维结构：列定义属性，行是实体实例。是大多数业务建模的基本单位。

### 使用场景

实体落库、关联表设计、分区与归档单位、权限按表授予。

### 实践与应用

• 一表一事，主键明确；关联用外键或应用层保证。
• 大表规划分区、归档与索引策略。
• 宽表与窄表在读写模式间取舍。

### 注意事项

• 万能大表难演进、难索引。
• 表名/列名语义要稳定，避免「复用列」藏多种含义。

### 关联术语

• 行 / 列：表的构成
• 主键 / 外键：标识与引用
• 索引：加速访问路径
• 模式：表所属结构空间
