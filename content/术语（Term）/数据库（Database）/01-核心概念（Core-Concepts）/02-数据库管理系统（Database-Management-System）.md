# 数据库管理系统（Database Management System）

### 缩写：DBMS

### 简述

管理数据库的软件系统：提供存储、查询语言、事务、并发控制、权限与恢复等能力。应用通过 DBMS 访问数据，而不是直接操作磁盘文件。

### 使用场景

选型（开源/云托管、OLTP/OLAP）、安装配置、权限与审计、性能与容量规划、高可用部署。

### 组成与要点

存储引擎、查询解析与优化、事务与锁/MVCC、日志与恢复、权限与连接管理；外围还有复制、备份工具与监控。

### 实践与应用

• 选型时对齐负载类型（高并发写、复杂分析、文档/图）与运维能力。
• 生产环境固定版本与参数变更流程，避免「顺手改参」。
• 监控连接数、磁盘、复制延迟、慢查询与锁等待。

### 注意事项

• 同名 SQL 方言在不同 DBMS 行为不同。
• 托管服务仍要管好账号、网络边界与备份策略。

### 常见做法

开发/测试/生产隔离实例；最小权限账号；基础设施即代码管理参数与角色。

### 关联术语

• 数据库：被管理的数据集合
• SQL：常见操纵语言
• 存储引擎：落盘与索引实现
• 连接池：应用侧连接复用
