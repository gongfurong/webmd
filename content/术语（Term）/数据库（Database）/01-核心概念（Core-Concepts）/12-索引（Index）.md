# 索引（Index）

### 缩写：无

### 简述

加速查找、排序与连接的辅助结构（常见 B+ 树、哈希、位图等）。用额外空间与维护成本换读取路径上的定位效率。

### 为何出现

全表扫描在数据量大时不可接受；需要按条件快速定位行。

### 使用场景

等值/范围查询、排序、唯一约束实现、连接驱动表选择。

### 在体系中的位置

查询优化器在统计信息基础上选择是否用索引、用哪条、是否回表。

### 实践与应用

• 按真实查询设计联合索引最左前缀。
• 写多读少表控制索引数量。
• 用执行计划确认索引命中与选择性。

### 注意事项

• 索引不是越多越快：拖慢写入、占空间。
• 低选择性列单建索引收益常差。
• 函数包列、隐式类型转换会导致索引失效。

### 对比与易混

主键/唯一约束通常由索引支撑；全文/向量索引是不同访问路径。

### 信号与度量

索引命中率、回表比例、索引大小、写入放大。

### 关联术语

• 表：索引建于其上
• 执行计划：是否用索引
• B+树 / LSM：常见实现结构
