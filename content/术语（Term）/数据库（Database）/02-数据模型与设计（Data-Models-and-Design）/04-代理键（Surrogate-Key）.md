# 代理键（Surrogate Key）

### 缩写：无

### 简述

无业务含义、专为标识行而生成的键（自增、序列、UUID、雪花等）。与自然键（业务属性）相对。

### 使用场景

主键选型、关联稳定、业务码可变时的解耦。

### 实践与应用

• 代理主键 + 自然键唯一约束是常见组合。
• 分布式环境评估 ID 生成策略（中心序列 vs 雪花 vs UUID）。
• 对外暴露 ID 时注意枚举与泄露风险。

### 注意事项

• 自增在分库分表下需改造。
• 无序 UUID 可能影响聚簇局部性。

### 对比与易混

代理键 vs 自然键；业务单号可作自然唯一键而非聚簇主键。

### 关联术语

• 自然键：业务键对照
• 主键：代理键常作主键
• 唯一约束：保护业务键
