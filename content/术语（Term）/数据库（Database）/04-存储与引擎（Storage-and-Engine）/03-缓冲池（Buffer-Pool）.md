# 缓冲池（Buffer Pool）

### 缩写：无

### 简述

缓存磁盘页的内存区域，使热点读写命中内存。大小与淘汰策略直接影响 OLTP 性能。

### 使用场景

内存规划、命中率调优、脏页刷盘与崩溃恢复理解。

### 在体系中的位置

位于存储引擎与磁盘之间；与 WAL 协同保证持久。

### 组成与要点

```mermaid
flowchart LR
  查询 --> 缓冲池 -->|未命中| 磁盘

```

### 实践与应用

• 为缓冲池预留足够物理内存，避免 OS 交换。
• 观察命中率与读磁盘次数。
• 大扫描可能污染缓冲，考虑分离或限制。

### 注意事项

• 盲目加大而不看工作集与 OS 内存会 OOM。
• 脏页过多延长关机与恢复。

### 信号与度量

缓冲命中率、磁盘读速率、检查点年龄。

### 关联术语

• 页：缓存单位
• 命中率：关键指标
• 脏页刷盘：与检查点相关
