# 覆盖索引（Covering Index）

### 缩写：无

### 简述

一次索引查找即可满足查询所需全部列，无需回表。用索引列集合「盖住」SELECT/WHERE/ORDER 所需。

### 使用场景

热点列表查询、减少随机回表、执行计划中 Using index。

### 实践与应用

• 把高频查询列纳入联合索引（注意宽度）。
• 用执行计划确认无回表。
• 与 INCLUDE 列（部分产品）区分设计。

### 注意事项

• 索引过宽损害写与缓存。
• SELECT * 很难覆盖。

### 关联术语

• 二级索引：基础
• 回表：被避免的操作
• 执行计划：是否 Using index
