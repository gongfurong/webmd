# 存储引擎（Storage Engine）

### 缩写：无

### 简述

DBMS 中负责数据如何落盘、索引、事务与恢复的组件层。同一 SQL 层可插拔不同引擎（如行存 InnoDB、列存、内存引擎），能力与限制差很大。

### 使用场景

建表选引擎、理解事务/外键/全文是否支持、性能调优边界。

### 在体系中的位置

SQL 层之下：缓冲池、页、redo/undo、索引结构。

### 实践与应用

• 选引擎前对齐事务、HA、索引类型需求。
• 参数调优针对具体引擎文档。
• 迁移引擎等于数据与特性双迁移。

### 注意事项

• 引擎不支持的约束会静默退化或报错，需验证。
• 备份工具与引擎格式绑定。

### 关联术语

• 页 / 缓冲池：核心构件
• 索引结构：B+ / LSM 等
• WAL：日志组件
