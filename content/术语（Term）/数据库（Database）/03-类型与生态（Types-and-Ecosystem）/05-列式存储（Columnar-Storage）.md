# 列式存储（Columnar Storage）

### 缩写：无

### 简述

按列而非按行组织数据的存储方式，利于只读少数列的大扫描与压缩，常见于 OLAP 与部分宽表分析。

### 使用场景

数仓、指标聚合、扫描型分析。

### 实践与应用

• 选列与压缩编码。
• 避免行式点查负载打列存。
• 与 ETL 批量写入匹配。

### 注意事项

• 单行宽更新成本高。
• 实时高并发事务非长项。

### 对比与易混

| | 列存 | 行存 |
|--|------|------|
| 分析扫描 | 友好 | 常回整行 |

### 关联术语

• 行存：对照
• OLAP：典型负载
• 压缩：列存优势点
