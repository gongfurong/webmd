# 文档数据库（Document Database）

### 缩写：无

### 简述

以 JSON/BSON 等文档为主要单元存储与查询的数据库，适合层级与半结构化数据，常可灵活演进字段。

### 使用场景

内容管理、用户配置、事件载荷、快速迭代产品。

### 实践与应用

• 按查询模式建模文档边界（避免过深嵌套无处索引）。
• 约定模式校验与版本字段。
• 多文档事务能力按产品核实。

### 注意事项

• 滥用巨型文档损害性能。
• 关联数据过多时 JOIN 弱，易数据重复。

### 关联术语

• JSON 文档：数据单元
• 聚合根：适合一体读写
• 事务：跨文档能力视产品
