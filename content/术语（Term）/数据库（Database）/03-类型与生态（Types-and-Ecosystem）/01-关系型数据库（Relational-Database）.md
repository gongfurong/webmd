# 关系型数据库（Relational Database）

### 缩写：RDBMS

### 简述

以关系模型为基础、通常以 SQL 为主要接口、强调模式与事务的数据库类型。是业务系统最常见的默认选择。

### 使用场景

交易、账户、订单、强约束业务状态。

### 实践与应用

• 默认假设 ACID 与约束，仍要核默认隔离。
• 与缓存/搜索协同，不把所有访问模式塞进一张表。

### 注意事项

• 半结构化与超大规模写入可能需其他类型补充。

### 对比与易混

| | 关系型 | 文档/键值等 |
|--|--------|--------------|
| 接口 | SQL 为主 | 多样 |

### 常见做法

规范化建模 + 关键路径索引 + 备份 HA 标配。

### 关联术语

• SQL：主要接口
• ACID：常见能力宣传点
• NoSQL：模型对照家族
