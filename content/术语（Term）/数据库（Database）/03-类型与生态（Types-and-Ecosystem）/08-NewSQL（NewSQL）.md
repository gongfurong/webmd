# NewSQL（NewSQL）

### 缩写：无

### 简述

一类试图在水平扩展的同时提供 SQL 与较强事务语义的数据库系统/架构取向，介于传统单机 RDBMS 与最终一致 NoSQL 之间。

### 使用场景

需要分片扩展又希望关系事务与 SQL 生态的场景。

### 实践与应用

• 核实跨分片事务隔离与延迟。
• 评估生态工具与运维成熟度。
• 用真实跨片负载压测。

### 注意事项

• 产品能力差异大，勿被品类名替代评测。

### 对比与易混

| | NewSQL | 经典单机关系库 |
|--|--------|------------------|
| 目标 | 扩展+SQL/事务 | 垂直扩展为主 |

### 关联术语

• 关系型：SQL/事务兼容目标
• 分片：扩展手段
• NoSQL：扩展路径对照
