# 主从复制（Primary-Replica Replication）

### 缩写：无

### 简述

主节点接受写，变更通过日志传到一个或多个只读副本。用于读扩展、备份源与高可用候选；副本可能延迟。

### 为何出现

单节点读/写与可用性触及上限。

### 使用场景

读写分离、备份从库、跨机房读、故障切换候选。

### 在体系中的位置

WAL/binlog → 传输 → 重放；拓扑可级联。

### 组成与要点

```mermaid
flowchart LR
  主库 -->|复制| 从库

```

### 实践与应用

• 监控复制延迟与中断。
• 关键读己之写不要默认走延迟副本。
• 定期做从库一致性校验。

### 注意事项

• 异步复制下主宕可能丢最近提交（视配置）。
• 错误 SQL 或表损坏会复制扩散。

### 对比与易混

主从 vs 多主；复制 vs 分片。

### 信号与度量

Seconds_Behind、位点差、复制错误计数。

### 关联术语

• 读写分离：常见上层用法
• 复制延迟：读旧风险
• 故障转移：主库不可用时
