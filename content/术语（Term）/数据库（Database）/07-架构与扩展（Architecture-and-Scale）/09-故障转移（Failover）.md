# 故障转移（Failover）

### 缩写：无

### 简述

主不可用时提升副本或切换到备用实例并改写流量的过程。成功标准是业务恢复与数据可接受性，而非「进程起来了」。

### 为何出现

硬件、网络、人为失误导致主服务中断。

### 使用场景

主库宕机、机房故障、计划内切换演练。

### 组成与要点

```mermaid
flowchart LR
  故障检测 --> 提升新主 --> 切流量

```

### 实践与应用

• 自动化与人工确认边界写清。
• 切换后校验只读实例重挂与序列/ID。
• 记录是否丢数据及位点。

### 注意事项

• 误判故障导致不必要切换。
• 旧主回网未隔离会脑裂。

### 信号与度量

检测时间、切换耗时、丢失事务、错误率恢复曲线。

### 关联术语

• 高可用：目标
• 主从：常见拓扑
• 健康检查：触发输入
