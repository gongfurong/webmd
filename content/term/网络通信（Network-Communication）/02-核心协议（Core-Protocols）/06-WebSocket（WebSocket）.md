# WebSocket（WebSocket）

### 缩写：WS

### 简述

HTTP 握手后升级的全双工长连接，便于服务端推送与双向消息。不是通用 HTTP 替代品；容量按连接数与状态扩展。

### 使用场景

协作、行情、通知、需低延迟双向的交互。

### 实践与应用

• 网关空闲超时与心跳对齐；重连要序号/去重。
• 水平扩展时想清连接粘滞与广播路径。

### 注意事项

• 代理可能破坏 Upgrade。
• 进程假活时连接仍在，需业务心跳或健康检查。

### 相关概念与术语

HTTP 升级、SSE/长轮询、保活、消息队列推送。

### 深入与掌握

L1 全双工长连；L2 重连与扩展；L3 多活连接路由。
