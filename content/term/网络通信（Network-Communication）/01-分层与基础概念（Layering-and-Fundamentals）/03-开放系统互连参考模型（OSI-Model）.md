# 开放系统互连参考模型（OSI Model）

### 缩写：OSI

### 简述

将网络功能拆成七层的参考/教学模型，便于对照「L4/L7」等说法。不是互联网唯一真栈，不必给每个产品硬贴唯一一层。

### 使用场景

教学、跨团队对齐层级语言、缩小排障范围。

### 实践与应用

• 用层缩小问题：链路→地址→端口→应用语义。
• 听到「七层负载」时对齐到 HTTP 内容路由这类能力。

### 注意事项

• 与真实 TCP/IP 实现并非一一对应。
• 过度教条会妨碍理解跨层优化与隧道。

### 相关概念与术语

TCP/IP 模型（更贴实践）、封装、负载均衡（L4/L7）。

### 深入与掌握

L1 说清层职责直觉；L2 按层排障；L3 知道模型边界。
