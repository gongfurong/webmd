# 远程过程调用（Remote Procedure Call）

### 缩写：RPC

### 简述

把远程调用做得像本地方法的交互范式；底层仍是网络消息。gRPC 等是实现，不是 RPC 的全部。

### 使用场景

内网微服务、IDL 二进制调用。

### 实践与应用

• 默认加超时、熔断、可观测；写路径考虑幂等。
• 控制同步调用链深度。

### 注意事项

• 本地错觉掩盖部分失败与重复执行。
• 与消息异步的边界要有意选择。

### 相关概念与术语

IDL、超时/重试、服务网格、REST/API、消息队列。

### 深入与掌握

L1 远程方法形态；L2 超时熔断；L3 调用图治理。
