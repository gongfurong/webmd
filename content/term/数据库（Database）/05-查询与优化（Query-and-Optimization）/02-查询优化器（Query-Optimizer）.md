# 查询优化器（Query Optimizer）

### 缩写：无

### 简述

根据统计信息与成本模型（或规则）为查询生成较优执行计划的组件。决定用何索引、如何连接与聚合。

### 使用场景

理解「同 SQL 不同性能」、直方图、提示（hint）、计划回归。

### 实践与应用

• 保持统计信息新鲜。
• 复杂查询可拆分或物化中间结果。
• 升级大版本后回归关键 SQL 计划。

### 注意事项

• 优化器不是真理：倾斜数据易误判。
• 过度 hint 会僵化。

### 相关概念与术语

执行计划、统计信息、成本模型、基数估计。

### 深入与掌握

L1 优化器选路径；L2 用统计与改写影响它；L3 引擎代价模型细节。
