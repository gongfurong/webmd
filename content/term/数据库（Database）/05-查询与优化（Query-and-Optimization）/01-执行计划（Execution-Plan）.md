# 执行计划（Execution Plan）

### 缩写：无

### 简述

优化器为 SQL 选择的具体执行路径：访问方法、连接顺序与算法、是否排序/临时表等。是性能分析的第一手证据。

### 使用场景

慢查询优化、索引是否生效、基数估计错误排查。

### 在体系中的位置

解析 → 改写 → 优化器选计划 → 执行器跑计划。

### 实践与应用

• EXPLAIN/分析实际执行（含实际行数）。
• 对比估计行与实际行。
• 改 SQL/索引后复测计划稳定性。

### 注意事项

• 绑定变量与字面量可能导致不同计划。
• 生产采样与实验室数据分布不同。

### 信号与度量

估计误差、扫描行数、临时磁盘、耗时算子。

### 相关概念与术语

查询优化器、统计信息、索引、全表扫描。

### 深入与掌握

L1 会看基本计划；L2 定位错误选择；L3 改写与提示/统计治理。
