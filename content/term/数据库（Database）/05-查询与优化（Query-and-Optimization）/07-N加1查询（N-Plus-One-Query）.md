# N加1查询（N+1 Query）

### 缩写：N+1

### 简述

先查列表 1 次，再对每行各查关联 1 次，共 1+N 次往返。ORM 懒加载中极常见，列表一大即雪崩。

### 为何出现

对象导航式访问隐藏了 SQL 次数。

### 使用场景

列表页变慢、ORM 性能问题、接口抓 SQL 日志。

### 实践与应用

• 用 join/预加载/批量 IN 一次取齐。
• 开发环境打印 SQL 次数。
• DTO 投影避免加载整图。

### 注意事项

• 预加载过度会变成巨大 join 或 IN 列表。
• 分页+预加载要防止加载过多关联。

### 信号与度量

单请求 SQL 次数、数据库 QPS 异常升高。

### 相关概念与术语

ORM、Join、批量查询、执行计划。

### 深入与掌握

L1 识别 1+N；L2 预加载改造；L3 读写模型拆分。
