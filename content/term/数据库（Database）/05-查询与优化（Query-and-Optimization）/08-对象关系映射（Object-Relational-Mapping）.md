# 对象关系映射（Object-Relational Mapping）

### 缩写：ORM

### 简述

在对象模型与关系表之间自动映射的技术/框架，减少手写 SQL，也引入 N+1、懒加载与脏检查等行为。

### 使用场景

业务 CRUD、领域模型持久化、快速开发。

### 实践与应用

• 关键路径会读 SQL 与计划。
• 批量与复杂报表可直写 SQL/存储过程。
• 明确会话/单元工作与事务边界。

### 注意事项

• 隐藏查询不等于没有成本。
• 二级缓存一致性复杂。

### 常见做法

仓储模式；规范预加载；禁止无索引条件的全表实体查询。

### 相关概念与术语

N+1、SQL、单元工作、仓储。

### 深入与掌握

L1 知映射作用；L2 避免 N+1；L3 复杂映射与性能规范。
