# 键值存储（Key-Value Store）

### 缩写：KV

### 简述

以键唯一映射值为核心接口的存储，查询模型简单、延迟低、易分片。值对存储不透明或仅有限结构。

### 使用场景

缓存、会话、配置、排行榜、高并发简单状态。

### 实践与应用

• 键设计含业务与版本空间。
• TTL 与内存淘汰策略。
• 持久化与主从是否满足丢数预期。

### 注意事项

• 不是通用查询引擎。
• 大 value 与热 key 是经典问题。

### 相关概念与术语

缓存旁路、Redis、分片、TTL。

### 深入与掌握

L1 简单 KV 接口；L2 键与过期设计；L3 持久与集群。
