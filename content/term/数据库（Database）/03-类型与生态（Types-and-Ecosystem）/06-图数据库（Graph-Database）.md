# 图数据库（Graph Database）

### 缩写：无

### 简述

以节点与边一等公民建模，优化多跳遍历与路径类查询的数据库。关系用边表达而非反复自连接表。

### 使用场景

社交关系、推荐、权限图谱、欺诈链路、知识图谱。

### 实践与应用

• 访问模式是多跳遍历再选型。
• 边类型与方向建模清晰。
• 深度遍历设边界防爆炸。

### 注意事项

• 全局超点（超级节点）需特殊处理。
• 不是所有「有关系」的数据都该上图库。

### 相关概念与术语

关系模型、遍历、属性图、RDF。

### 深入与掌握

L1 点边模型；L2 遍历查询；L3 超点与分布式图。
