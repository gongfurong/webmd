# 列式存储（Columnar Storage）

### 缩写：无

### 简述

按列而非按行组织数据的存储方式，利于只读少数列的大扫描与压缩，常见于 OLAP 与部分宽表分析。

### 使用场景

数仓、指标聚合、扫描型分析。

### 实践与应用

• 选列与压缩编码。
• 避免行式点查负载打列存。
• 与 ETL 批量写入匹配。

### 注意事项

• 单行宽更新成本高。
• 实时高并发事务非长项。

### 对比与易混

列式存储 vs 列族数据库（Wide Column）不完全同一概念。

### 相关概念与术语

OLAP、压缩、宽表、行式存储。
