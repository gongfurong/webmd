# NewSQL（NewSQL）

### 缩写：无

### 简述

一类试图在水平扩展的同时提供 SQL 与较强事务语义的数据库系统/架构取向，介于传统单机 RDBMS 与最终一致 NoSQL 之间。

### 使用场景

需要分片扩展又希望关系事务与 SQL 生态的场景。

### 实践与应用

• 核实跨分片事务隔离与延迟。
• 评估生态工具与运维成熟度。
• 用真实跨片负载压测。

### 注意事项

• 产品能力差异大，勿被品类名替代评测。

### 对比与易混

NewSQL vs 分库中间件 + 传统库；vs 分布式 SQL 引擎。

### 相关概念与术语

分片、分布式事务、SQL、CAP。

### 深入与掌握

L1 知取向；L2 选型评测；L3 事务与扩展边界。
