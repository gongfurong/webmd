# 视图（View）

### 缩写：无

### 简述

基于查询定义的虚拟表：不（或不必）单独存数据，查询时展开为底层 SQL。用于简化访问、封装逻辑与权限裁剪；物化视图则缓存结果。

### 使用场景

复杂连接的稳定接口、行列级权限暴露、报表逻辑复用、逻辑解耦物理表变更。

### 实践与应用

• 对外提供稳定视图，底层表可演进。
• 权限：授予视图 SELECT 而非基表。
• 性能敏感路径慎用多层嵌套视图。

### 注意事项

• 可更新视图有严格限制，勿默认当表写。
• 物化视图有刷新延迟与一致性窗口。

### 对比与易混

视图 vs 物化视图；视图 vs 应用侧 DTO。

### 相关概念与术语

SQL、物化视图、权限、模式。

### 深入与掌握

L1 视图是命名查询；L2 用视图做封装与权限；L3 物化与刷新策略。
