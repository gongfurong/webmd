# 主键（Primary Key）

### 缩写：PK

### 简述

唯一标识表中每一行的列或列组合：非空且唯一。是行定位、关联与许多聚簇存储的锚点。

### 使用场景

实体标识、外键引用目标、ORM 映射、分片键讨论的基础。

### 实践与应用

• 优先稳定、紧凑的代理键（如雪花/UUID 策略需评估顺序）。
• 业务自然键可做唯一约束，不一定当主键。
• 联合主键控制列数与顺序。

### 注意事项

• 可变业务码当主键会导致级联更新痛苦。
• 无序 UUID 作聚簇主键可能加重页分裂（引擎相关）。

### 对比与易混

主键 vs 候选键（候选中选出的一个）；主键 vs 唯一索引（主键还含非空与语义角色）。

### 相关概念与术语

外键、候选键、代理键、聚簇索引。

### 深入与掌握

L1 主键唯一标识行；L2 选键策略；L3 分布式 ID 与聚簇影响。
