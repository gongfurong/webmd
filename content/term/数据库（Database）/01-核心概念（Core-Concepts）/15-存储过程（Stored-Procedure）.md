# 存储过程（Stored Procedure）

### 缩写：无

### 简述

存储在库内、可被调用的过程化程序单元，可包含多条 SQL 与控制流。用于封装业务逻辑、减少往返；也带来移植性与版本治理成本。

### 使用场景

批量处理、强一致多步写、遗留系统逻辑下沉、减少应用与库的网络往返。

### 实践与应用

• 明确边界：哪些逻辑在应用、哪些在库。
• 版本与迁移同应用发布对齐。
• 监控执行时长与锁持有时间。

### 注意事项

• 过度使用导致逻辑分散、难测、难扩缩。
• 长事务过程易拖垮并发。

### 对比与易混

存储过程 vs 触发器（事件驱动）；vs 应用服务方法。

### 相关概念与术语

触发器、函数、事务、RPC。

### 深入与掌握

L1 知其为库内程序；L2 编写与权限；L3 架构上取舍是否下沉逻辑。
