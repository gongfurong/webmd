# 增删改查（Create Read Update Delete）

### 缩写：CRUD

### 简述

对持久化资源的四类基本操作：创建、读取、更新、删除。是接口设计与权限划分的常用骨架，不绑定特定存储。

### 为何出现

需要统一描述资源生命周期操作，便于 API、权限与审计对齐。

### 使用场景

REST 资源接口、后台管理、权限模型（按操作授权）、测试用例分层。

### 组成与要点

C 插入；R 查询（可含列表/详情）；U 部分或全量更新；D 物理删除或逻辑删除。

### 实践与应用

• 更新与删除必须有明确标识与权限边界。
• 读多写少时区分查询模型（列表投影 vs 详情）。
• 逻辑删除要约定过滤默认行为。

### 注意事项

• 真实业务常有「状态流转」超出简单 U。
• 批量 CUD 要事务与幂等策略。

### 信号与度量

各操作 QPS、错误率、P99 延迟。

### 相关概念与术语

SQL DML、幂等、REST、软删除。

### 深入与掌握

L1 四类操作含义；L2 设计安全的更新删除；L3 复杂领域操作与 CRUD 的边界。
