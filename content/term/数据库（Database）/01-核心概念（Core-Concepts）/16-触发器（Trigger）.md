# 触发器（Trigger）

### 缩写：无

### 简述

在表上特定事件（INSERT/UPDATE/DELETE 等）自动执行的过程。用于审计、级联维护、强制复杂约束；副作用隐式，调试成本高。

### 使用场景

审计日志、冗余字段同步、遗留库的数据规则兜底。

### 实践与应用

• 优先能用声明式约束则不用触发器。
• 触发器逻辑保持短小、避免连锁触发。
• 文档化存在哪些触发器及顺序。

### 注意事项

• 隐式逻辑易被迁移/同步工具忽略。
• 批量装载时触发器可能成为性能瓶颈。

### 相关概念与术语

存储过程、约束、CDC、审计。

### 深入与掌握

L1 事件自动执行；L2 安全使用场景；L3 与 CDC/应用事件的取舍。
