# 数据字典（Data Dictionary）

### 缩写：无

### 简述

描述数据含义、类型、归属与质量规则的元数据集合。可在库内（系统目录）或独立文档/平台中维护。

### 使用场景

跨团队对齐字段含义、治理指标口径、接入数据平台、合规盘点。

### 实践与应用

• 核心表维护「字段业务定义 + 负责人」。
• 与迁移/代码生成联动减少漂移。
• 敏感字段标记分级。

### 注意事项

• 字典与真实库结构长期不一致会失去信任。
• 只堆技术类型不写业务语义用处有限。

### 相关概念与术语

模式、元数据、数据治理、系统目录。

### 深入与掌握

L1 知字典是元数据；L2 维护关键表字典；L3 平台化治理。
