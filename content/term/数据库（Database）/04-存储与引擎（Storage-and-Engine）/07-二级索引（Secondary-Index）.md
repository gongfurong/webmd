# 二级索引（Secondary Index）

### 缩写：无

### 简述

非聚簇的附加索引，用于按非主键条件定位；常见叶子存主键再回表取整行。

### 使用场景

where/join/order 加速、唯一约束、执行计划中的 index lookup。

### 实践与应用

• 联合索引服务多条件。
• 覆盖索引减少回表。
• 统计信息过期会导致错选索引。

### 注意事项

• 每个二级索引增加写成本。
• 回表点查过多可能不如扫聚簇。

### 相关概念与术语

聚簇索引、覆盖索引、回表、最左前缀。

### 深入与掌握

L1 辅助查找；L2 设计联合与覆盖；L3 优化器选择博弈。
