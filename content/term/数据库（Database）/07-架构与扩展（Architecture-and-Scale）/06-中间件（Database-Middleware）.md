# 中间件（Database Middleware）

### 缩写：无

### 简述

位于应用与数据库之间的代理/组件，提供分片路由、读写分离、连接复用、防火墙或协议转换等能力。

### 使用场景

分库分表治理、统一读写分离、连接爆炸治理、SQL 审计。

### 实践与应用

• 评估协议兼容与跨片 SQL 限制。
• 中间件本身要 HA。
• 可观测：慢 SQL、路由错误、连接。

### 注意事项

• 多一层故障点与延迟。
• 部分 SQL 语义在分片下不支持。

### 常见做法

与配置中心协同；灰度路由规则；备援直连应急通道（受控）。

### 相关概念与术语

分片、读写分离、连接池、代理。

### 深入与掌握

L1 知其定位；L2 配置路由；L3 极限场景与逃生。
