# 故障转移（Failover）

### 缩写：无

### 简述

主不可用时提升副本或切换到备用实例并改写流量的过程。成功标准是业务恢复与数据可接受性，而非「进程起来了」。

### 为何出现

硬件、网络、人为失误导致主服务中断。

### 使用场景

主库宕机、机房故障、计划内切换演练。

### 组成与要点

故障检测 → 选新主 → 数据追平/接受差距 → 元数据与 DNS/VIP/代理切换 → 应用恢复 → 旧主隔离。

### 实践与应用

• 自动化与人工确认边界写清。
• 切换后校验只读实例重挂与序列/ID。
• 记录是否丢数据及位点。

### 注意事项

• 误判故障导致不必要切换。
• 旧主回网未隔离会脑裂。

### 信号与度量

检测时间、切换耗时、丢失事务、错误率恢复曲线。

### 相关概念与术语

高可用、复制、脑裂、RTO。

### 深入与掌握

L1 知切换含义；L2 执行 runbook；L3 设计自动与防脑裂。
