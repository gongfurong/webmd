# 读写分离（Read-Write Splitting）

### 缩写：无

### 简述

写与强一致读打主库，可容忍延迟的读打副本的流量编排方式。常依托主从复制与中间件/驱动路由。

### 使用场景

读多写少业务、报表与详情分流、降低主库负载。

### 实践与应用

• 明确哪些 API 必须读主。
• 写后读在延迟窗口内粘主。
• 副本故障时降级策略（打主或报错）。

### 注意事项

• 延迟导致用户「刚写看不见」。
• 全部读打从仍可能把从打满。

### 相关概念与术语

主从复制、最终一致性、连接池、中间件。

### 深入与掌握

L1 写主读从；L2 路由规则；L3 会话一致与多从负载。
