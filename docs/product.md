# 产品定义（Product）

| 字段 | 值 |
|------|-----|
| 名称 | **WebMD** |
| 版本 | 0.2.x |
| 形态 | 个人 Wiki / 静态知识站 |
| 内容真相 | 仓库目录 `content/` |
| 运行时 | 纯静态（无服务端业务进程） |

---

## 1. 要解决什么问题

- 把**本地文件夹式知识**（Markdown + 附件 + 表格 + 图示）变成**可分享、可检索的网站**。  
- 接近成熟 Wiki 的阅读体验（树、大纲、搜索、路径），但**不绑定**重型 CMS / 在线协作后端。  
- 多格式「打开即看」，而不是一律下载。

---

## 2. 目标用户

| 用户 | 诉求 |
|------|------|
| 个人知识工作者 | 本地 Git 管理 content，静态站阅读 |
| 小团队知识库 | Pages 部署，无运维服务端 |
| 开发者/AI 代理 | 清晰约定、可扩展预览类型 |

---

## 3. 产品目标

| ID | 目标 | 度量 |
|----|------|------|
| G1 | content 即真相，可 Git  diff | 无隐藏 DB |
| G2 | 主路径纯静态可部署 | Cloudflare Pages 可上线 |
| G3 | MD 阅读体验专业 | GitHub 风 + 树 + 大纲 + 关键字/向量混合搜索 |
| G4 | 常见办公/媒体/图示可预览 | 见 formats.md |
| G5 | 扩展按类型插件化 | preview-framework |
| G6 | 目录可对照、可审计 | `pages` 路径对齐 content |

---

## 4. 核心原则（不可轻易推翻）

1. **内容与壳分离**：文稿在 `content/`，壳在 `src/` + `scripts/`。  
2. **不写回源文件**：预览与会话编辑（如表格）不保存进原件。  
3. **旁路资源 `_Res_*`**：预生成/导出物与源同级夹，**不进导航树**。  
4. **类型方案独立**：每种预览 prepare/shell/bind/style 成套。  
5. **dev ≈ prod 渲染语义**：中间件与 SSG 共用 `render-page`。  
6. **dist 可删重建**：真相只在 content（及已提交的 `_Res_*`）。  
7. **不上公网渲染 API**（隐私/离线）。  

---

## 5. 产品特点 / 优势

| 特点 | 说明 |
|------|------|
| 静态优先 | 便宜、快、无后端攻击面 |
| 多格式一体 | MD + Office 旁路 PDF + 表 + 媒体 + 图示 DSL |
| 路径可审计 | `/pages/` 与 content 相对路径对齐 |
| 轻依赖可选 | ffmpeg / LibreOffice 仅本机预生成 |
| 图示可控 | Mermaid / PlantUML / Graphviz 客户端；重格式走导出图 |

---

## 6. 非目标（明确不做）

| 非目标 | 原因 |
|--------|------|
| 在线协作编辑 content | 无后端；用 Git |
| 账号/权限系统 | 静态站范围外 |
| draw.io / Excalidraw / XMind 全量 Web 编辑器 | 过重；导出 SVG/PNG |
| 公网 PlantUML 服务 | 隐私与稳定性 |
| 站内解压浏览压缩包 | 未做 |
